## 在效果面板中下载

选中图形或组合，在 **合成 → 后处理 → 手绘风格** 中调节原有参数，直接在画布观察效果。面板底部的 **下载填充 Shader 参考包** 导出源码、当前帧参数与贴图；没有独立试验台或第二套调参窗口。使用基础值编辑时导出基础参数；编辑动画时导出当前帧求值。

目前仅手绘填充提供参考源码，支持纯色、平行排线、交叉排线、圆点、虚线和锯齿线排线。原图、无填充、连续锯齿和放射线尚无对应参考，下载时会给出提示。其他后处理尚未提供此入口。

## 如何理解两张预览图

- `editor-preview.png` 是当前节点在编辑器中的效果，包括已有描边及其他后处理。
- `reference-preview.png` 是包内参考 Shader 的填充结果，不包括 Rough.js 轮廓描边、重复描线和高级填充细节。
- `parameters.json` 的 `parameters` 是参考 Shader 实际使用的参数；`sourceEffect.values` 保留当前手绘原参数，`mapping` 和 `limitations` 写清映射与差异。粗糙度按原值除以10映射为线条起伏，超出 Shader 范围的值会被限制，原值仍保留。二者不是像素一致的转换。

遮罩由当前节点进入手绘效果前的内容提取，保留子节点效果并跳过本节点手绘及后续效果。按当前轮廓来源、阈值和简化参数生成轮廓；快照采用画布坐标、保持比例，长边最多512像素。变换和当前帧被烘焙进遮罩，未导出节点树或关键帧。动画或复杂变换需要目标项目适配。

下载的 `mask.png` 把覆盖度写入RGB，Alpha恒为1。**引擎应读取红通道，关闭sRGB，使用Clamp采样**。不能读取Alpha，否则整张会变成实心。尺寸以遮罩短边512设计像素为基准；圆点模式的width是半径。包中的双语README说明完整参数与材质约定。

## 交给 AI 接入

在帮助菜单下载 **创作Skill**，提供参考包、目标项目与需求，例如：

> 根据包内参考 Shader 接入这个项目的URP材质。先对比编辑器图和参考图，保留交叉排线与颜色；说明描边等差异如何处理。请实际编译并检查透明边缘。若需要新的遮罩，用Texture Forge制作。

`handdrawn-fill.hlsl` 是核心函数，`HanddrawnFillURP.shader` 是Unity 6 / URP 17参考封装；内部GLSL参考图使用同源核心数学。**浏览器参考图通过不代表目标引擎已编译通过**，JSON记录 `engineCompilation: not-run`。Skill指导AI读取实际源码、参数和目标环境，完成引擎适配；制作配套纹理仍用现有创作流程。

下载不会修改项目、节点和撤销记录。此包不是图库资源ZIP，请勿导入图形库。
