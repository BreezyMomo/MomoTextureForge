## 1. 顶部入口与帮助菜单

- **使用说明**：编辑器内置的文字手册，可搜索参数和操作。
- **详细说明 ↗**：直接打开项目 README，从教程索引进入带标记的分步操作手册。
- **AI 工具**：顶部独立入口，集中管理 Skill 安装、ZIP 下载、MCP 设置、图库目录导出与项目交接。
- **GitHub 仓库 ↗**：新标签打开源码仓库，可反馈问题和参与贡献。
- **Gitee 仓库 ↗**：新标签打开国内源码镜像，可阅读文档与下载仓库，内容自动跟随 GitHub 同步。
- **投币支持**：位于右上角，与图形库、组合示例、布局、帮助并列，点击即弹出微信赞赏码，可使用微信扫码自愿打赏，支持工具持续开发与维护。

手绘效果面板的 **下载填充Shader参考包** 提供源码、当前参数、遮罩和对比图，使用创作Skill指导AI接入游戏；见[Shader参考包](14-shader-reference.md)。

在 **AI 工具 → 安装 Skill** 选择Agent与所需Skill，点 **选择目录并安装…**，在系统窗口中选择位置并授权。个人使用按面板推荐路径选择已有的Skill目录；工程内使用可选择工程根目录，工具自动补齐对应的Agent子目录。每次安装都自行选位置，取消不会写入文件。

安装完成后复制下一步的启动说明给 AI，由 AI 按 Skill 准备环境并启动服务，无需用户自己安装运行依赖。成功安装文件不等于Agent已加载；详情见[安装说明](../skills/texture-forge-author/references/installation.md)。

每个Skill行右侧的 **下载 ZIP** 提供对应的完整压缩包，可手动解压安装。Skill 不是图形资源，不要导入图库。

## 2. 给 AI 当前可用的图形目录

![从图库导出 AI 图形目录](images/ai-catalog.png)

> 图中标记：1 选择目录范围；2 生成可提供给 AI 的目录；3 复制目录内容。

1. 从 **AI 工具 → MCP → 导出 AI 图形目录** 打开图库的目录导出；也可在 **图形库**搜索或筛选资源。
2. 勾选资源，或按目录窗口提供的范围导出当前结果。
3. 点 **导出 AI 图形目录**，复制内容或下载 JSON。
4. 把目录、目标描述和必要的参考截图一起提供给 AI。

目录包含当前资源的名称、分类、参数和能力。它不包含当前画布、图片像素或公式源码；需要 AI 判断视觉效果时另外提供截图。Skill 不携带固定图形清单，避免推荐当前没有加载的资源。

## 3. 将 AI 结果导回工具

- 操作建议：按“选哪个节点 → 哪个面板 → 参数 → 预期结果”执行。
- 创作 JSON：**创建资源 → 导入文件**选择或粘贴并解析，检查预览后导入图库。
- 生成器 JSON：也可直接在 **创建资源 → 生成器**输入，验证代码、步骤与参数。
- 图片 / SVG：使用图片页检查背景、比例和轮廓。
- 完整项目ZIP：使用 **文件 → 打开项目**，节点、组合、遮罩、效果顺序、关键帧及图形依赖仍可编辑。保存项目后可交回AI继续处理。

编译通过不等于视觉正确，保存前查看默认值、参数范围和多个时间位置。不要将“上次成功预览”当成新代码已成功。

## 4. 反馈问题时提供什么

从帮助菜单打开 GitHub 仓库，描述操作步骤、预期与实际结果、浏览器信息，附相关截图。可附最小演示项目或资源包来复现；提交前自行检查其中是否包含不适合公开的素材。

命令行验证和输出示例：[AI 创作 CLI](../AI_AUTHORING_CLI.md)。

创作Skill自带离线节点创作工具，首次安装运行环境后无需打开网站。AI可查询实际图形目录、从零创建或修改原生项目，并渲染多个时间点检查结果；见[离线项目流程](../skills/texture-forge-author/references/offline-projects.md)。

## 5. 将当前网页作品直接交给AI

首次使用按 **安装 Skill → 让 AI 启动 MCP → 配置 MCP** 进行。在 AI 工具中安装创作 Skill，进入下一步复制启动说明发给 AI。AI 自行检查运行环境、安装缺少的依赖并启动服务，验证后再让用户回到第 3 步连接页面、复制 MCP 配置到客户端；不要求用户自己运行安装或启动命令。浏览器询问时允许本地网络访问。

AI 先通过 `forge_pages` 按作品名称和页面 ID 选择目标，再调用 `forge_capture({pageId})` 获取完整主画布快照，读取节点、效果、关键帧、源码与图片并渲染参考图。用户编辑后重新捕获；同一 snapshotId 始终对应同一版本。需要创作时，AI 通过 forge_schema / forge_catalog 查询实际操作与图形，再用 forge_edit 提交配方；修改可撤销，旧版本请求会被拒绝。完成后重新捕获并渲染验证。关闭面板仍连接；**断开当前页面** 仅撤销该页，刷新或关闭后需重新开启。处于图形预览时先返回主画布。

配置、网站来源与工具说明见[网页作品与 MCP 连接](../skills/texture-forge-author/references/live-editor.md)。网页、本机服务和 MCP 客户端须能访问同一台电脑；纯云端客户端不能直接访问本机回环地址。
