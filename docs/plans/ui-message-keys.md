# 界面语言统一消息键

目标：界面使用稳定的语义 key，所有语言文件结构一致，文案修改不改变调用身份。

1. 提取中文与英文独立词库，提供统一解析、插值与缺失回退；语言配置仍在构建时固定。
2. 迁移程序调用、声明式 HTML、内置名称和状态/错误文案；不翻译用户命名、代码或参数 aliases。
3. 更新审计、测试、开发说明与相关 Skill，验证语言切换、资源身份、导出和窄屏布局。
4. 构建离线与静态网页，保留改动供审核，不提交或推送。

约定：采用 menu.file、common.close、preview.* 等语义键；键一经分配保持稳定，不随显示文本自动生成。新增语言需注册词库并在构建校验中检查相同键集与插值占位符。图形元数据继续使用 variable + aliases。

- 构建校验键集、占位符、注册语言和界面引用；错误及 Worker 传递保留消息键和插值参数。
