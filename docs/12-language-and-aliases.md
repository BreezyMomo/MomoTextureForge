# 语言、图形名称与参数别名

[手册目录](README.md) · [返回项目首页](../README.md)

## 设置参数的显示语言

在编辑器右上角的语言下拉框选择 **简体中文** 或 **English**，选择后立即切换，无需打开弹窗或确认。

用户只能选择构建中已提供的语言，不能输入语言编码、增加语言类型或修改回退顺序。参数先查找所选语言的非空别名，再按内置语言顺序查找其余语言，均没有时显示变量名。例如选择 English 后按 `en → zh-CN` 回退。

设置独立保存在当前浏览器，不随画布项目传递，不产生撤销记录，也不修改参数值、关键帧、公式或导出图像。内置参数、主编辑器、图库与资源编辑窗口、时间轴、预览与导出、布局、示例页和内置使用说明提供中英文。项目名、用户节点名、代码及用户输入保留原文；图形名称按资源自身的多语言别名显示。

### 界面词库与参数别名是两套数据

界面固定文案使用稳定的语义 key。例如 `menu.file` 在两个文件中分别定义：

```json
// web/locales/zh-CN.json
{"menu.file": "文件", "common.close": "关闭"}
```

```json
// web/locales/en.json
{"menu.file": "File", "common.close": "Close"}
```

代码调用 `uiText('menu.file')`，动态句子调用 `uiFormat(key, ...values)`；HTML 使用 `data-i18n="menu.file"`，属性使用 `data-i18n-title`、`data-i18n-aria-label` 等显式绑定。修改中文措辞只改中文文件，不修改 key 或英文文件，也不按中文反查翻译。

各语言共用相同键集和插值占位符。`node tools/i18n-audit.mjs` 检查键、占位符与界面引用，静态构建也会执行该校验。新增语言需在 `web/language-config.json` 配置，并在 `web/locales/catalogs.js` 注册对应 JSON 文件。运行时缺失文案按构建配置回退，全部缺失时显示 key，便于发现遗漏。

分类名称通过稳定分类 ID 选择界面词库内容。内置和自定义图形名称使用资源自身的 `name + aliases`；图形参数使用 `variable + aliases`，都随资源导出，填写的是实际名称而非界面消息 key。项目名、节点名和代码保持原文。

### 构建语言配置（开发者）

语言编码、原生名称、默认语言由 [web/language-config.json](../web/language-config.json) 定义：

```json
{
  "default": "zh-CN",
  "languages": [
    {"code": "zh-CN", "name": "简体中文"},
    {"code": "en", "name": "English"}
  ]
}
```

配置在构建时内嵌进静态网页。修改语言类型需由开发者修改该文件、补齐对应界面翻译并重新构建。`languages` 的顺序决定其余语言的回退顺序，用户所选语言优先；`default` 是首次使用的默认语言。语言编码必须规范且唯一，默认语言必须存在。

## 编辑图形的多语言名称

创建、编辑或保存图形时，在名称旁展开 **多语言名称**：

1. 默认名称照常填写，不要求添加别名。
2. 点 **添加语言**，从固定下拉框选择简体中文或 English，并填写名称。已有的同语言项不能重复添加。
3. 保存到图形库，或导出创作 JSON、完整资源 ZIP；名称别名都会随资源保存。组合保存窗口、图形列表的重命名窗口也支持该控件。

```json
{
  "name": "默认护盾",
  "aliases": {"zh-CN": "冰霜护盾", "en": "Frost Shield"}
}
```

显示顺序为所选语言、构建配置中的其余语言、默认 `name`、资源 ID。别名最多32种，每个名称最多80字；用户只能编辑当前构建支持的语言，导入资源中未启用语言的别名会保留。

图形定义的顶层 `aliases` 表示图形名称，`parameters[i].aliases` 表示参数名称，二者独立。内置图形也采用该格式，不在界面词库中重复维护名称。未提供 `aliases` 的旧资源继续显示默认名称。

图库和图形列表会同时搜索默认名称、所有语言别名和 ID，因此 English 界面输入“冰霜护盾”也能找到 Frost Shield。远程目录携带别名，无需下载完整图形即可搜索和显示；发布与缓存保留该数据。

加入画布时，当前显示名称成为新节点的初始名称。之后节点名称独立保存，切换语言或更新资源都不会覆盖已有节点名。修改名称/别名属于资源内容修改，会产生新版本或图形列表的个人修改；单纯切换语言不会改变资源、哈希、项目或撤销记录。

## 编辑参数别名

打开 **图形库 → 编辑图形**，在对应参数下展开 **多语言别名 / Aliases**：

- 公式变量是参数的稳定名称，如 `radius`。
- 每一行从下拉框选择语言，再填写对应别名；语言编码不可手输，已选语言不能重复添加。
- 可以只填写一种语言，也可以移除全部可编辑别名。资源中已有但当前构建未启用的语言别名会保留，保存、导出不丢失；它们不进入语言选择列表。
- 下拉参数的选项也可以分别配置多语言别名；选项的数值不变。
- 保存新图形或更新原图形后，别名随资源一起保存。

公式变量必须填写，在同一个图形内不能重复。允许 ASCII 字母或下划线开头，后续为字母、数字或下划线，最多80字符；排除 GLSL 关键字、`gl_` 前缀、双下划线及宿主保留名称，如 `time`、`uv`、`input0`。不能与公式中调用的函数冲突。修改变量名后需要同步修改公式引用并通过预览；仅改别名不需要改公式。

生成器编辑器显示变量名，并允许编辑别名。自定义生成器修改变量名通过生成器 JSON 完成；内置生成器变量还参与算法配置，不提供直接改名。

画布参数面板悬停可查看变量名。用户填写的项目名、节点名、图形名和代码不自动翻译。

## 创作 JSON

公式和生成器使用同一套参数元数据：

```json
{
  "variable": "radius",
  "aliases": {
    "zh-CN": "半径",
    "en": "Radius"
  },
  "min": 0.1,
  "max": 0.8,
  "step": 0.01,
  "default": 0.5
}
```

`aliases` 可以省略或设为 `{}`。空白别名不参与匹配。语言标签会规范化，例如 `zh-cn` 等价于 `zh-CN`；同一语言不能重复。每个参数最多32种别名，每项最多128字符。资源数据格式保留规范语言标签，以便跨构建使用；网页编辑控件只列出当前构建配置的语言。

下拉选项示例：

```json
{
  "variable": "profile",
  "aliases": {"zh-CN": "轮廓", "en": "Profile"},
  "type": "select",
  "min": 0,
  "max": 1,
  "step": 1,
  "default": 0,
  "options": [
    {"value": 0, "variable": "round", "aliases": {"zh-CN": "圆形", "en": "Round"}},
    {"value": 1, "variable": "square", "aliases": {"zh-CN": "方形", "en": "Square"}}
  ]
}
```

选项省略变量名时按其数值生成稳定名称，例如 `value0`；选项缺少所有匹配别名时显示该名称。

旧的 `label` 仍作为中文别名读取；显式提供 `aliases` 后以该映射为准，不再把 `label` 当作未配置的兜底语言。新创作文件建议使用 `variable` 与 `aliases`。完整资源 ZIP、公式创作 JSON 和生成器 JSON 都保留别名。切换显示语言不改变资源内容哈希；修改别名本身属于资源内容修改，会生成新的资源版本。
