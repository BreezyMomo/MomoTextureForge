# 当前内置图形范围

工具内置全部 284 个图形，5 个公共 GLSL 库完整保留。当前没有因本次审查而外置的图形。内置扩展机制、资源编辑和用户图库继续使用原有接口。

## 实现与资源

除用户指定调整的能量护盾外，其余图形保留原实现、参数、默认值和范围。能量护盾移除圆形遮罩和半径参数，铺满图形区域，版本为 2；其余图形版本为 1。5 个公共库与审查基线逐字节一致，目录和分类顺序保持完整目录的顺序。

局部周期文件全部保留，包括 16 个已启用定义和 3 个未启用文件。公共库保留全部函数及现有署名、许可文本。当前公式指纹见[实现清单](builtin-implementation.json)。

外部图库独立管理，工具不自动订阅或下载。资源包自带公式和依赖，项目及图形库导出携带所选资源依赖。外部图库不因恢复内置图形而修改。

缩略图、单 HTML、离线 ZIP 和两个 Skill 均按当前实际目录生成。

## 维护与验证

不为制造实现差异改写公式；后续修改应针对明确问题或用户确认的视觉改进。历史初审及复核中的保留、重写、外置建议均不再决定当前收录范围。

- `npm test`：目录、原公式指纹、资源导入导出及编辑器逻辑回归。
- `npm run validate:definitions`：目录和参数定义检查。
- `node tests/builtin-release-browser-check.mjs --parameters`：逐图浏览器渲染、参数极值、动画和无缝路径检查，并生成当前缩略图。
- `npm run build:standalone`：重建离线版及两个 Skill。
- `node tests/release-smoke-browser.mjs`：无缝专项、导出和离线图库检查；需先启动本地服务并构建离线版。

浏览器检查使用 Playwright 和本机 Edge。报告和原始备份只放在忽略的 test-results 中。本文件记录工程采用范围，不是授权认定。
