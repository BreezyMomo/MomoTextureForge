# 发布范围

当前工具内置全部 284 个图形，保留原主体、周期公式、矢量/法线入口及全部 5 个公共库。图形效果不因发布范围整理而改变；后续按用户要求将能量护盾改为无圆形遮罩的全区域六边网格。不为制造实现差异改写公式。完整范围见[内置图形说明](builtin-release.md)和[实现清单](builtin-implementation.json)。

外部图库独立管理，不默认订阅、下载或嵌入。本地外部图库的 284 个资源包已核查完整性，图形入口、公式和资源校验值均与审查基线对应；恢复内置图形不修改外部图库。

## 工程维护

- 保留内置图库扩展和自包含资源包机制。
- 5 个公共库及全部辅助函数、专用分支和现有署名、许可文本均保留。
- 主体、周期与矢量接口、参数、导入导出和浏览器渲染通过项目检查。
- 缩略图、两个 Skill、单 HTML 和离线包从当前实际目录生成。
- 初审和复核的技术分类仅作历史参考，旧的重写、外置建议已撤回，不作为当前收录规则。

## 发布前事项

收录范围是工程采用决定，不是第三方再分发许可证明。OgeeFlowerTile 的图案由用户确认本人原创；公共库按用户决定整库采用，保留现有声明。这些决定不替代实际来源与许可记录。

项目根目录尚无 LICENSE，需由权利人确定项目授权。按实际分发内容核对第三方许可正文及声明；现有 web/vendor/PSD-LICENSES.txt 应随相关代码保留。

本地依赖元数据中，ag-psd、base64-js、esbuild 为 MIT，pako 为 MIT AND Zlib，Playwright 为 Apache-2.0；具体要求以对应许可正文和实际分发内容为准。

当前私有仓库历史包含完整图库。本次不改仓库可见性、不重写历史、不执行发布；正式公开的范围、许可和仓库方案应另行决定。
