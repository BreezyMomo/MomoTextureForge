# 变换、排列与合成

## 三种容易混淆的尺寸

1. “变换/排列 → 节点占用区域”：位置X/Y相对父区域，中心通常0.5/0.5；区域宽高0～1，旋转用度，轴心0～1。锁定区域宽高比例用于联动；水平镜像翻转；区域适配可随区域拉伸或保持比例。
2. 图形专属半径/宽度：只改变区域内部图案。整体太小先辨别是区域小还是图形小。
3. “实例尺寸”：排列出来的每一份内容大小。图形参数改变每份内容本身，排列参数改变分布。

固定画布是导出边界，越界内容裁切；要整体移动画布内容，用父组合。Y轴视觉方向可先小幅调整确认，勿与图片像素坐标混用。

## 通用边界处理

选中图形或组合 → 变换/排列 → 节点占用区域 → 边界处理，三选一：“裁切到节点区域”截断内容；“允许超出节点区域”保留外伸内容；“无缝重复”将越界内容接到对侧。多选可批量改，支持离散关键帧。蓝框只决定逻辑宽高、轴心、对齐和排列格距；超框不自动放大蓝框。祖先分别决定裁切、外伸或回绕，金色画布始终裁切，预览与导出一致。同一节点只保存一个 boundary 模式；无缝模式下才显示图形接缝处理和融合宽度。

组合允许超出后，可显示移到蓝框外的子节点；图形允许超出后可显示公式在区域外的轮廓、描边和滤镜。图片/矢量/生成器不会补出资源外不存在的像素，但其位置或光晕可超出父级。遮罩仍作用于实际内容；无缝重复仍按逻辑区域回绕，不扩大平铺周期。若仍被截断，沿父链检查边界处理及遮罩。“内容边界对照”和“跨格光点排列”可直接对比；“无缝光晕接续”演示子级允许超出、父级无缝及光晕跨角回绕。

## 单块拼图

拼图块只有一个主体；在“图形”顶部选择圆头凸耳、方头卡扣、梯形燕尾或波浪接口，调接口圆润度；上／右／下／左四边分别选择平边、凸耳、凹口，支持轮廓和实心。展开“主体四角：0为直角”，左上／右上／右下／左下圆角可分别设置0～0.4；0为直角，数值越大圆角越大。主体圆角会让格点留空，紧密拼接时内部接角保持0。主体占满蓝框，凸耳允许伸出蓝框；“变换/排列 → 网格”按主体排布，调大接口不改变格距。相邻边须一凸一凹，接口样式、大小、颈部和圆润度一致，尺寸和朝向对应。平整外框用平边；图库有对应样式、角块、边块、圆角主体预设。“拼图接口与圆角”“单块拼图网格”“彩色拼图板”可直接打开。拼图块默认允许超出，普通节点默认裁切；需要跨过父级时，也将对应父组合设为允许超出，最终画布仍裁切。

## 图形内部UV

位置在“图形 → 图形内部 UV”。UV改变内部采样，不等于移动节点边框。UV缩放0.1～8、旋转−360～360°、偏移X/Y−2～2；滚动速度−2～2和方向角决定纹理运动；漩涡−6.28～6.28扭曲内部纹理，极坐标采样把纹理映射到径向/角向空间。缩放是采样倍率，先小幅改变观察密度，不承诺等于画布放大。复位UV可排除采样变形。

## 区域内的内容排列

在“变换/排列 → 排列方式”选择。图形重复自身内容；组合默认重复整个子树，也可选择每个位置只使用一个直接子节点，见下文“实例内容”。

| 排列方式 | 配置与效果 |
| --- | --- |
| 关闭 | 单个内容 |
| 网格排列 | 网格类型矩形/斜向/六角；行列数控制数量；矩形可行错位，斜向隔行错位，六角有横/纵错列。先分单元格，再在每格绘制内容 |
| 随机散布 | 密度分布为整个区域或密度图案；实例数量是目标数量，最小中心距离越大越难容纳全部实例；密度阈值/对比度影响偏好的区域 |
| 环形排列 | 圈数、布局半径、内半径比例、环覆盖比例、圈间错位；按间距均匀分布或每圈等数量。前者内圈可更少，后者每圈数量一致；实例朝向可保持、朝外或沿圆周切线 |
| 螺旋排列 | 黄金角：发散角（约137.508°形成常见均匀效果）、中心留空；规则：螺旋圈数和内半径。外圈尺寸倍率改变由内到外的大小 |
| 沿路径 | 贝塞尔起点、两控制点、终点，路径缩放和起止进度决定覆盖范围；按数量等距或按间距；末端尺寸倍率可渐缩，朝向可沿切线或垂直路径 |
| 对称排列 | 对称份数与偏角，选择仅放射旋转或旋转＋镜像成对；适合对称花纹 |
| 边框排列 | 矩形/圆角矩形的宽高、圆角、沿线偏移、数量/间距与切线/法线朝向 |
| 沿图形轮廓 | 组合首个子节点提供透明度轮廓，其余子节点作为沿线装饰 |
| 人字 / 编织 | 人字纹或篮式编织，每个重复块 4×4 格，长砖按格子拉伸；重复块行列各 1～8 |
| 规则拼接 | 组合子节点声明右/上/左/下接口，按匹配关系选择；1～16 行列、种子及无缝首尾匹配 |

公共项：整体旋转改变布局；高级“随机扰动与位置”包含位置/尺寸/旋转随机、排列种子及排列中心X/Y。相同种子有助于复现布局。排列中心偏移默认0，不等于节点位置默认0.5。
“居中”恢复排列中心；网格用“铺满网格”，随机散布用“铺满区域”（半径设0.5、中心偏移归零，仅更新现有参数，保留实例尺寸/数量/旋转/随机设置），其他模式用“分布适配”。铺满区域扩大点的采样范围，防堆叠仍可能限制数量，不保证图形恰好贴满四边；旋转仍按当前设置生效。“每份动画相位偏移”−1～1让重复内容错开局部动画；它不是把所有内置time公式变成无缝循环。

“实例比例”默认“保持设计比例”：每份图案的单位设计区域按所在格子/节点短边适配，排列中心仍覆盖完整区域，宽画布和竖画布不会压扁图案；也可显式选择“随区域拉伸”。不要把整个组合的“区域适配”改成保持比例来替代，它会缩小整个布局范围。未排列节点沿用已有区域适配。旋转、防堆叠短边距离、实际宽高周期、选区和展开同步；改变画布比例可重新排布，但改变输出像素尺寸不应换布局。
“展开为独立节点”固定当前排列布局，便于逐个调整，保留内容动画，可撤销；实例数很多会增加节点数量/开销。部分排列最多512份，随机和间距约束可能导致实际数量低于目标。具体数值范围见layout-parameters.md，切换模式会改变可见项。

## 新增排列的操作与边界

可先推荐“组合示例 → 示例分类 → 新增排列”，十三个示例包括无缝光晕接续、内容边界对照、跨格光点排列、拼图接口与圆角、单块拼图网格、彩色拼图板、圆角边框灯带、星形轮廓光点、人字镶嵌底纹、篮式编织底纹、渐隐装饰点阵、波浪流场线阵、接口匹配管线。打开后选外层节点 → 变换/排列；拼图板按块分别编辑，不是只导入示例图片。

沿图形轮廓需要组合，首个直接子节点是来源，后续节点是装饰；来源可为图形/组合/透明图片。来源最终透明度以固定256×256采样，包含孔洞；阈值选择轮廓，法向偏移移向两侧，“显示轮廓来源”只显示来源一次。不透明图片沿矩形边缘布点，可先去背景或切亮度遮罩。极细轮廓受采样限制，修改导出像素不会重排。边框和轮廓支持数量或间距采样、偏移与朝向。

人字/编织把内容拉伸进长砖区域，每块4×4格，最多512份。可开边界处理 → 无缝重复接续边缘，用平铺检查验证旋转和画布比例变化。

“排列变化：渐变与流场”适用于现有排列：横向/纵向/径向/实例顺序渐变尺寸、透明度和旋转，可反向；波浪偏移/旋涡扭转改变位置并可跟随转向，流场相位支持关键帧。随机散布防堆叠开启时暂停这些变化以保留间距；设置仍保存。位置渐变跨边缘可能出现节奏突变。

规则拼接需要组合，直接子节点为候选，在“图块接口配置”声明其四边连接；图案的接口应绘在边中点，不会自动分析图片。禁用子节点可移出候选。关闭无缝重复则外围接口封闭，开启则首尾匹配；种子控制候选选择。无解时补充端点、转角/空白块；搜索超限可减小行列或换种子。格子按区域拉伸，不应用渐变/流场以免接口断开。

## 组合的实例内容：整组、随机、取模

先把不同花型放到同一个组合的直接子级，选这个组合并开启排列，再找“变换/排列 → 实例内容”。图形节点或关闭排列时不显示这个选择。

| 选项 | 每个排列位置绘制什么 | 调整方式 |
| --- | --- | --- |
| 整个组合 | 全部子节点合成的内容 | 适合把一组装饰当作一个单元重复 |
| 随机一个子节点 | 从已启用的直接子节点等概率选一项，允许重复 | 改“杂排种子”重新抽选，与高级排列种子共用；没有权重或保证每种出现的选项 |
| 按顺序循环（取模） | 按排列点生成序号循环选项；A、B、C对应A、B、C、A、B、C…… | 用节点树调整候选顺序；固定的是点序号对应项，不是画布某个坐标永远对应某项 |

子组合整体算一项，不递归抽内部所有后代；未启用节点跳过，动画暂时隐藏的候选仍保留名额，遮罩不参与选择。只有一个候选就重复它，没有候选则透明。随机选择在同种子下不因刷新、动画播放或导出自行重抽；取模选择不随时间/种子变化，但种子仍可改变随机点位置。更改候选数量、顺序或启用状态会改变映射。关闭排列后显示整个组合。

## 随机散布的防堆叠与疏密

“随机散布”下，密度分布为“整个区域”或“密度图案”时可开启“防堆叠”，再设置“额外间距”（0～0.5，步长0.005）。默认关闭。它按每份实际选中的图形、实际尺寸与旋转避让，支持随机/取模混排，设置随项目和组合资源保存。

- 读取可见内容的偏移外包圆，透明留白不再按整个节点区域占位，随机尺寸也不统一按最大尺寸占位。细长、空心、凹形图案仍采用保守外包圆，不能承诺轮廓紧密嵌套。
- “额外间距”和“最小中心距离”是两道同时生效的约束，按当前排列区域短边尺度计算；前者补在可见范围之间，后者约束中心。大留白先检查这两项，再检查实际图形大小和布局半径。
- 数量是目标。空间不足、密度图案限制或有限采样尝试会使“实际生成 / 目标”较低；提高目标不会无限塞满。先减小实例尺寸/间距/最小中心距离，或扩大布局半径，再观察实际数量。
- 开启边界处理 → 无缝重复时也避让跨边缘邻居。子节点变换、效果及每份动画相位参与可见采样；组合最外层遮罩/轮廓/后处理在整组排列后应用，不属于单个实例的碰撞范围。

可见采样固定128×128，alpha阈值1/255并留少量边缘余量；极细、极淡的细节可能低于采样精度。不要描述为精确像素碰撞，或保证播放期间所有中间时刻都绝不接触。

## 比例与展开编辑的选择

需要横幅/竖幅时，在“画布设置”修改画布比例；保留排列节点“实例比例 → 保持设计比例”。布局仍使用完整宽高，每份内容按物理格子短边适配；这是保留原设计的宽高关系，不会把原本椭圆的设计强制改圆。未排列的节点用自己的“区域适配 → 保持比例”；若祖先节点主动拉伸整组，需检查那一层设置。旧项目未记录实例比例时也默认保持设计比例，想保留格子拉伸外观可选“随区域拉伸”。

排列实例共享内容，拖动/改图形参数不等于只修改其中一份。需要逐个移动、换大小或编辑时，先选排列节点点击“展开为独立节点”：固定当前时刻的布局和随机/取模选择，复制对应内容及内部动画，保留外层时间/合成；之后原排列参数动画不再驱动这些独立节点。可一次撤销；大量展开会增加节点和渲染开销。先保存项目，展开后可在节点树选单项编辑，不要把导出图片当作可恢复的工程。

## 空间无缝与检查

先开启预览下方“平铺检查”观察四边，再选目标节点开启“边界处理 → 无缝重复”。
- 自动：内置周期图形使用周期规则，独立形状跨边缘重复；周期约束可能调整数量、UV旋转或扰动，不保证任意参数都保持原样。
- “通用：边缘融合”：对缺少专用规则的图案混合两侧边缘；融合宽度0.05～0.45，变大更柔和但可能产生重影。
- 组合重复合成结果，子节点接缝需分别处理。图形内部接缝与最终画布两侧是否匹配是两件事。
这是空间重复，不保证动画首尾衔接。

## 合成、颜色与遮罩

透明度在“颜色”页顶部，0～1，越小越透明；顶部颜色快捷区默认折叠，展开后可用0～100%的滑条或数值调整，两处同步。组合控制整个组合，父子透明度相乘，支持关键帧。“颜色”页签和快捷区负责配色，可继承父级或自定义；组合还可保留子节点颜色/组合统一配色。继承来源可跳转，也可复制当前配色为独立配色。要不同子节点分别着色，父组合优先保留子节点颜色。“合成”页保留混合方式、遮罩、轮廓和滤镜。
自定义配色/组合统一配色下，“纯色填充”保持填充颜色，边缘只影响透明度；“数值渐变”按图案强度映射颜色，不是按空间从左到右渐变。渐变色标支持2～8个，位置0～1，有配色预设、增加/删除色标、恢复双色。需要空间渐变时使用相应渐变图形。

| 混合方式 | 操作意图 |
| --- | --- |
| 正常 | 常规按透明度覆盖 |
| 相加 | 叠亮，常用于发光叠层，可能产生高亮溢出 |
| 最大值 | 取较亮分量，有助保留亮部 |
| 相乘 | 压暗/调制已有颜色 |
| 相减 | 减去颜色亮度，不等同于抠透明孔 |
| 滤色 | 提亮叠层 |
| 差值 | 显示颜色差异，重叠可能变暗 |
| 叠加 / 柔光 | 调整对比关系，柔光更缓和 |
| 颜色减淡 | 强烈提亮，需控制透明度 |
| 遮罩 / 反向遮罩 | 保留/挖去覆盖区域，只影响同组中排在它前面的内容，后面的不受影响 |

做透明镂空用反向遮罩，而不是画一个与背景同色的实心形状。将底图和遮罩放同一组合，可避免误伤其他图层。

轮廓处理：关闭/外描边/膨胀/收缩，宽度按区域短边比例0～0.1。外描边只保留外侧线；膨胀扩大、收缩减小覆盖。组合先合成再取轮廓。要填充＋外线，复制一层：一层保留填充、一层外描边。
后处理：亮度−0.6～0.6；对比度0.1～3；伽马0.1～4；输入低/高重映射输入范围，输出低/高改变输出强度范围；反相图案翻转图案数值。改色阶可能同时影响遮罩强度和渐变，先复位后处理再定位问题。
