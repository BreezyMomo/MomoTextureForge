# 示例配方与排错

<!-- doc-language -->
[简体中文](recipes.md) · [English](recipes.en.md)
<!-- /doc-language -->

以下是未针对用户画布渲染的建议起点。先核对图形清单和当前面板，观察实际结果再微调，不说已实现精确复刻。

## 从完整技能与分层光效预设开始

先查看顶栏“组合示例”的当前卡片；预设属于示例入口，不等于所有用户图库都含有固定图形清单。点“在画布中编辑”会打开独立项目，不直接合入原画布。完整技能的结构通常为主体、接触亮斑/亮核、扩散环和余留粒子/烟雾；用节点树逐层选择、隐藏或改色，先确认视觉职责再改参数。

单次技能从透明出现到完全消散；按卡片已有时长导出，关闭循环，检查首帧、爆发和末帧。图形时间、透明度、尺寸和布局半径可能都有绝对轨道，改基础值会被覆盖；需录制修改轨道或调整外层时间范围。要作为组件复用，选最外层效果组合保存到图形列表，再加入目标画布；检查其局部进度、外层时间和末尾透明度。保存项目保留结构，导出PNG不保留可编辑节点。

多层光帘先分开检查后景/中景/前景光带，再看薄膜、细丝与浮尘。光帘模式可调底部位置、高度、竖向光丝密度；旧版仅有流动纹理时不要让用户找不存在的模式，按当前面板和目录判断。不同层可使用不同的图形时间曲线，非周期噪声可平滑往返以闭合；“循环导出”本身不能保证无缝。检查各层起止值与运动方向，再决定是否修改配色和透明度。

## 可替换单元点阵

若当前示例提供可替换单元点阵，打开后选最外层排列组合；行列、实例尺寸、位置随机、大小随机和种子都在“变换/排列”，可固定常用模块到节点树。把新图片/组件作为该组合的直接子节点，删除或禁用不需要的候选，父组合布局仍保留。“按顺序循环（取模）”交替使用候选，“随机一个子节点”随机混排，“整个组合”将所有子级叠成同一单元。子组合也可作为候选。需要单独编辑某一份时先保存，再展开实例。

## 波形环纹与独立辉光

以当前目录提供的环纹参数为准：频率控制径向周期，基础半径留空中心，环宽占一个周期的比例，流速正负决定向外/向内，相位用于多层错开；波形可为平环、正弦或噪声，平环不受扰动影响。正弦角向波数为整数以闭合圆周。环宽为0可保留旧的渐升条纹，不等于隐藏图形。修改流速后用“流速×图形时间变化为整数周期”检查径向循环，并核对所有层的其他运动。

亮核与外晕应保持为独立节点，分别调范围、颜色与透明度；不要仅增亮同一层导致亮核和外晕一起变大。作为组件保存整个组合，透明背景和后处理随节点复用。

## 多种花型杂排并避免挤在一起

1. 将需要的花型从图库加入画布，放到同一个组合的直接子级。子组合也可作为一种花型；先分别调好轮廓、颜色和相对大小。
2. 选父组合，“变换/排列 → 排列方式 → 随机散布”，“密度分布 → 整个区域”，“实例内容 → 随机一个子节点”。可从目标数量50、实例尺寸0.12开始，观察花型尺寸后再调；这不是保证能放下50份的配置。
3. 点击“铺满区域”，将现有布局半径设为0.5并居中；它不会改实例尺寸、数量或种子，之后仍用布局半径收放分布。想换花型选择时改“杂排种子”。
4. 开启“防堆叠”，先将“额外间距”和“最小中心距离”调到0，确认实际数量，再小幅增加所需间隔。空心花环按外包圆避让，环内不能再塞花；数量不足时先减小实例尺寸。
5. 横幅/竖幅保留“实例比例 → 保持设计比例”。需要平铺时开启这个组合的“边界处理 → 无缝重复”，用“平铺检查”查看边缘；防堆叠也会计算边缘另一侧的邻居。
6. 保存项目。若要单独移动某朵花，选父组合“展开为独立节点”，再选相应节点编辑；展开会固定当时的布局和选择，可撤销。

## 固定顺序交替与宽竖幅

需要A、B、C、A、B、C时，选父组合“实例内容 → 按顺序循环（取模）”，在节点树把直接子节点按A、B、C排序。网格适合可见的顺序排布；随机散布也按点的生成序号取模，并非按画面从左到右排序。改种子可移动随机点，但同一点序号选哪一项保持固定；增删/禁用/重排候选会改映射。

需要改变画布形状时，在“画布设置”改比例，排列节点保留“实例比例 → 保持设计比例”；布局区域继续随画布伸展，单个设计保持比例。不要为了修正单朵花而将整个父组合缩进正方形。只想拉伸每份图案时才选“随区域拉伸”；改比例可能让防堆叠重新排布，改导出像素尺寸不会自行换布局。

## 呼吸光环

1. 从图库添加圆形到图形列表，再“＋ 添加”到画布；选节点“图形”，例如半径0.62、内径0.5形成环，羽化0保持清楚。
2. “图形 → 节点颜色 → 配色 → 自定义配色”，将“着色方式”设为“纯色填充”，设置需要的颜色。
3. 透明度在进度0设0.35，开启录制后在0.5设1、1设0.35；使用平滑插值。关闭录制播放。
4. 想要外侧柔光可复制一层，降低透明度并增加羽化，检查不要填死中心。是否使用相加由目标亮度决定。
5. 选3秒、24FPS导出序列图集；这组透明度首尾一致，但若加入time运动需另查衔接。

## 一圈标记与多圈花纹

1. 先添加一个合适的基础形状，调成小标记；再到“变换/排列 → 环形排列”。
2. 从圈数1、数量12、布局半径0.35、实例尺寸0.12开始。改数量控制疏密，改实例尺寸控制每份大小，改布局半径控制环大小。
3. 实例朝向在保持方向/朝外/切线间比较。增加圈数、设置内半径比例和圈间错位形成多圈；保持子图形可辨认。
4. 多层环放同一父组合，想整圈旋转时给父组合旋转加关键帧，而不是只转单个子图形。

## 透明镂空

1. 一个组合内先放底图，再放用于开孔的圆形（节点顺序在底图后）。
2. 选圆形，“合成 → 混合方式 → 反向遮罩”。只影响该组合内前面的内容。
3. 用棋盘格确认孔是真透明；若图形完全消失，检查遮罩大小、顺序和同组范围。

## 沿曲线排珠或拖尾

选择点状/小形状 → 变换/排列 → 沿路径。拖动路径控制点；先用按数量等距，调实例尺寸避免重叠。末端尺寸倍率小于1让末端变小；沿切线方向适合条状图。若需要渐隐，需另设计内容/动画或节点层次，不把“尺寸倍率”说成透明度控制。

## 可平铺纹理

先选图形，在“变换/排列”开启边界处理 → 无缝重复；预览下方开启平铺检查。自动模式优先；仍有接缝再根据节点提示尝试通用边缘融合。观察四角与左右/上下边，特别是旋转或父组合裁切后。最终导出一张纹理，不把平铺检查的多张预览当作导出内容。

## 排错顺序

| 现象 | 优先检查 |
| --- | --- |
| 找不到某个图形 | 先在图库搜索并加载，基础图形下拉不是完整图库；具体名称以当前图库及导出的 AI 图形目录为准 |
| 改参数没有变化 | 是否选中正确节点、编辑主选节点还是试编辑资源；是否在改预览值而不是默认值；公式是否使用参数；是否报错保留旧预览 |
| 动画参数改完又跳回 | 是否处于普通模式由轨道求值覆盖；录制用于改关键帧，基础值用于改基础状态 |
| 图形在动但关键帧为空 | 可能是图形time或UV滚动；检查图形内置动画与UV |
| 想静止但还在动 | 同时检查time自动播放、参数关键帧、父组合动画和UV滚动 |
| 轮廓被切掉 | 节点区域、父组合边界、图片缩放、UV、最终画布边界；先复位UV并缩小内容定位 |
| 图案颜色不对 | 图片显示模式、节点配色继承、父组合统一配色、混合方式和后处理 |
| 每个位置仍显示所有花型 | 选的是父组合吗、排列是否开启、“实例内容”是否仍是整个组合；候选需为直接子节点 |
| 取模顺序看起来乱 | 取模按生成点序号，不按随机点的屏幕坐标排序；需要直观顺序可用网格，并核对候选启用状态和树顺序 |
| 防堆叠后一片空、数量上不去 | 读实际/目标数量；检查实例尺寸、额外间距、最小中心距离、密度约束及布局半径，空心/细长图案的外包圆可能较保守 |
| 数量加大仍只铺在中间 | 点击铺满区域并检查布局半径/中心偏移；再检查父节点占用区域、区域适配和密度分布，数量不能扩大采样范围 |
| 横幅中的圆环被压扁 | 图片节点先查图形→图片比例=保持原图比例；排列查实例比例=保持设计比例，公式节点和祖先的区域适配另查，图形自身椭圆参数也需核对 |
| 只想改一份却一起变化 | 排列内容共享，先保存项目并展开为独立节点，再逐个编辑 |
| 内部白色背景没删 | 去背景是否限制仅边缘连通，取消可能同时删除主体同色部分 |
| 只想留下红色花型 | 位图编辑器选提取指定颜色，吸取红色并调容差/边缘过渡，再检查内部孔洞；不只设置背景色 |
| 导入ZIP提示缺少manifest.json | 普通创作JSON合集需解压后选JSON；Skill ZIP不导入图库，正式资源ZIP由工具导出，不补写空清单 |
| SVG锯齿/坑洼 | 检查原图分辨率与阈值、去毛刺和平滑；提高采样不能恢复原图不存在的细节 |
| SVG太大或操作慢 | 减少细节/采样尺寸、减节点/实例数；像素够用就保留位图 |
| 导出与预览不同 | 导出是整个画布、实际输出外观和当前时间；忽略辅助背景/单独预览/查看缩放；先做低分辨率单帧验证 |
| 动画循环跳变 | 不重复尾帧只去冗余帧，不保证内置time、UV或关键帧闭合；比较起止帧后决定修改运动还是接受连续播放 |
