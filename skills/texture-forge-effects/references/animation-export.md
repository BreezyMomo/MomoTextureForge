# 动画与导出

## 两套时间

- 播放条在折叠的“动画编辑与时间轴”外，播放/重新播放、播放时长（0.05～600秒）、当前范围进度可直接操作。切换图形不应作为停止播放的步骤。
- 节点关键帧保存为0～1局部进度；节点在父级中的区间控制开始/结束和播放速度。
- 支持time的图形在“图形 → 图形内置动画”提供自动播放、运动速度−10～10、时间偏移−600～600秒。按累计秒数×速度＋偏移计算，不会随0～1时间轴自动复位。关闭自动播放可设置图形时间（秒，−36000～36000），定格或为该时间添加关键帧。
- 内置动画自动播放关闭不一定停止节点变换关键帧；关键帧停用也不一定停止内置time运动。先判断用户想停止哪一种。

## 关键帧与时间轴

1. 选节点，展开“动画编辑与时间轴”；确认编辑范围是全部内容还是已进入选中节点，必要时“返回画布时间”。
2. 在起始进度开启“● 录制”，调整目标参数；移动进度再调整同一参数。首次录制会保留起点基础状态；参数旁关键帧按钮也可显式添加。
3. 关闭录制再播放检查，避免调整时误加帧。“基础值/编辑基础值”暂时旁路本节点参数动画编辑基础状态；退出后恢复，保存/导出仍包含动画。
4. 时间轴可过滤全部节点/选中节点及子树/有动画节点；支持时间吸附0.01、只吸附关键帧、按导出FPS或关闭，缩放1～20。
5. 选菱形可拖动、编辑时间/数值；Shift多选或框选，复制/粘贴/删除关键帧。曲线页编辑参数变化；分段插值为线性、平滑、保持、自定义切线。枚举/开关按离散值变化，不承诺渐变插值。
6. 轨道作用可绝对值、加到基础值、乘以基础值。先用绝对值减少理解成本。可清空本节点关键帧或关闭“启用本节点参数动画”；动画模板在“添加轨道 / 动画模板”里，模板包括呼吸缩放、淡入淡出、旋转一周、弹出、横向进入、UV滚动；应用会替换同名参数轨道，其他轨道保留。

蓝色节点区间可拖动/拉伸；循环或非线性映射显示只读预览，双击进入本地时间后编辑，不把预览中的重复关键帧当作独立帧。

右侧“动画”：父级区间开始/结束0～1；播放一次/循环/往返；重复次数0.01～64，往返的2个单程才是一次往返。开始前/结束后可保持边界状态或隐藏。高级时间控制包括源动画起止进度、父级时间相位偏移、固定动画百分比、线性/缓入缓出/保持和时间重映射曲线。
时间重映射横轴本地时间、纵轴源进度，会影响节点及子树时间；不是参数值曲线。实例相位偏移在排列页。

## 导出选择

主界面“导出…”导出整个画布，忽略预览贴图类型、单独预览、查看缩放与辅助框。画布设置负责画布宽高比例；导出面板负责实际像素宽高（1～4096，按比例联动）。

| 格式 | 使用场景与限制 |
| --- | --- |
| PNG当前帧 / 复制PNG8 | 静态图、透明图；PNG有8/16位，复制固定8位，浏览器拒绝复制时下载PNG |
| PSD当前帧分层 | 保留可拆分层级，复杂效果可能合成为像素层；不是所有效果都可拆成矢量 |
| PSD矢量轮廓 / SVG矢量轮廓 | 当前帧，透明度阈值（默认50%）和平滑控制轮廓；各部分转单色，渐变、羽化、半透明过渡会简化，保留孔洞；SVG最大2MB |
| EXR当前帧 | 高精度数据，可ZIP无损压缩，依赖设备浮点支持 |
| 逐帧PNG ZIP | 分开的动画帧文件，可供其他工具组装 |
| 序列帧图集PNG / EXR | 帧按列数排列于一张图，需在使用端按同FPS播放；不会直接生成GIF/视频 |
| 查看序列帧图集 | 预览图集排布 |
| 三档图集PNG ZIP / 三档尺寸PNG ZIP | 批量尺寸，当前分别为64/128/256单帧档与256/512/1024静态档 |

输出外观在导出面板“输出内容”中单独选择颜色/高度/法线/自定义RGBA；画布预览切换为法线不会自动改变此选项。法线强度0～20，支持Sobel/Scharr、翻转X/Y、反转高度与预平滑0～8。画布法线生成参数与导出共享并随项目保存；三维模型、灯光、粗糙度、金属度、视角与纹理重复只用于查看，不写入导出图片。RGBA可选高度、反相高度、法线X/Y/Z、0、1、0.5、透明度、法线斜率。矢量轮廓不使用高度/法线通道输出。勾选透明背景或设置画布背景颜色；预览棋盘格不会被自动导出。
动画导出配置FPS（1～120）、秒数、图集列数（1～32）。按摘要确认实际帧数。“循环导出不重复尾帧”避免重复结束帧，不修复运动首尾不一致。若需要无缝动画，用受控关键帧回到同一状态，并检查内置time动画、UV滚动等是否也闭合。
序列/图集预算提示出现时按提示降低尺寸/帧数/复杂度：最多10000帧，序列总采样像素预算33554432；图集边长最多8192、总像素16777216，设备还可能有更低限制。单张PNG的预览预算处理见下节，不因预览超预算就直接判断4096 PNG无法导出。轮廓超过50000锚点仅警告，SVG体积仍有限制。不要把配置上限解释成能以最大尺寸导出最大帧数。
开始导出后显示阶段和进度，可取消；后台处理SVG/PSD及图片编码，GPU渲染仍可能短暂停顿。失败后读取具体提示，参数恢复可操作；建议降低输入负载而不是反复点击。
## 单张PNG内存处理

单张PNG在原定尺寸/位深下按需合成、及时释放临时图像，最多缓存2份排列源，不沿用预览384MiB预算和单帧求值次数门限。复杂导出可能更慢；支持的硬件会只重绘图案覆盖区域。实际浏览器/显卡分配失败或上下文丢失仍可能导致失败，不能承诺任意复杂画布都能导出。其他格式保持原有路径和限制。
