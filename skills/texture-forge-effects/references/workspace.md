## 主界面

- 顶栏左侧为画布名称，可直接修改。画布名称后是当前画布操作：文件（新建画布、打开项目、保存项目、分享配置）、撤销/重做、画布设置、导出。随后是创作资源入口：图形库、组合示例；右侧依次为布局、外观、语言、投币支持、帮助。撤销/重做使用箭头图标，悬停可查看快捷键。窗口较窄时，画布设置收进文件菜单，组合示例收进图形库旁的下拉菜单。帮助菜单包含使用说明、直达 README 与图文教程的“详细说明”、下载创作Skill、下载效果指导Skill，以及在新标签页打开的“GitHub 仓库”链接（查看源码、反馈问题或参与贡献）；两个Skill下载均为ZIP，将解压后的文件夹交给支持Skill的AI。
- 默认从左到右是占满工作区高度的四栏：左侧图库、节点树、画布预览、参数面板，宽度约为13%、10%、59%、18%。画布列包含画布工具与动画播放。参数面板在单选时显示“图形（含颜色）/ 变换/排列 / 动画 / 合成”；多选默认显示批量编辑。未选节点时没有这些参数。已有布局保留，通过“布局 → 恢复默认布局”采用四栏。
- 预览右上角可将当前结果另存为新资源、保存个人资源更改，或保存整个画布；已有画布实例保持原样。

错误提示在右上角持续显示，可展开详情或手动关闭，不会被后续成功提示覆盖。若旧列表包含已下架或依赖缺失的图形，工具会备份原始数据、隔离失效条目并恢复其他资源；可从提示下载原始备份及当前可用依赖。备份不等于正式资源 ZIP，不要指导用户直接清空浏览器存储或用其他图形替代失效内容。只对本次新发现的失效条目提醒；保留历史备份不会在刷新时重复弹出旧提醒。

左侧图库顶部按“全部 / 收藏 / 最近 / 动态”切换，再叠加搜索和多选分类标签；不按图片、公式或组合区分。分类组内任一选中项匹配，“全部”清除分类筛选，取消最后一个选项也恢复不限。分类来自内置与个人列表，不要求固定清单。卡片上的星形按钮用于收藏，播放图标标记动态图形。切换语言保留筛选，不修改项目或资源。

内置分类按外观与用途组织，公式和生成器可在同一类中；只看会动的资源时再选“动态”。分类以当前目录为准，不把旧的“径向”“形状”“法阵”“特效素材”当成与新分类并列的固定入口。旧内置副本按当前分类显示，缺少早期内置标记的条目也会兼容；不需要清缓存、删除副本或重新添加，自建/导入资源保留自己的分类。搜索框的 × 一键清空关键词并保留筛选；收藏、改参数与筛选复用已加载的预览。

顶栏“外观”独立设置完整主题、控件风格、页签与紧凑/舒适密度。主题包括玄黑鎏金、水墨朱砂、月白墨青、青瓷流金、青花映月、敦煌矿彩和藕荷雪青，主题自身决定底色与明度，不另设深浅模式，也不跟随系统。控件样式包括标准、精致、轻盈、简洁、柔和、极光、律动、影院和糖果；页签可独立选择方形、分段、胶囊或下划线。切换风格保留主题、交互颜色、页签和密度；选择主题重置四种自定义交互色，之后可分别调整动作、选中、导航和参数控件色。新浏览器默认玄黑鎏金、精致、紧凑；保存仅记住当前浏览器，取消或 Esc 恢复打开前的完整设置，不改变作品或导出。动画、区间、关键帧和录制的状态含义跨主题保持一致，配合图标与文字；界面过渡遵循系统的减少动态效果设置。

单选时可用参数模块标题的图钉，把操作控件固定到节点树；旁边的范围菜单可应用到全部节点（含新节点），个别节点仍能取消。不适用的模块隐藏，节点与图形选择模块不提供固定。快捷控件与参数面板共用编辑、关键帧和撤销。绑定随同一浏览器内的预览添加、节点复制和保存后重新插入保留，不进入项目/资源文件。通道曲线快捷预览打开的完整窗口与贝塞尔放大窗口都可拖动标题栏移开；方向键移动，Shift 加大步长。

## 自定义面板布局

节点树、左侧图库、画布预览、参数面板、时间轴可分别停靠。上述左右位置指默认布局；用户可拖动面板顶部标签改变位置。拖到另一个面板边缘出现蓝色提示后松开，可上下/左右拆分；拖到中央合并为标签，点击标签切换。拖动两面板之间的分隔线改变比例。

面板右上角“↗”在网页内悬浮当前标签；Alt 拖动标签也可悬浮。悬浮窗口左上角握柄移动，右下角握柄缩放；将标签拖回其他面板即可停靠。悬浮不创建独立浏览器窗口。拖动中按 Esc 取消。

右上角“×”关闭当前面板，内容保留；从顶部“布局”菜单勾选名称重新打开。找不到参数或时间轴时先检查面板是否关闭或位于其他标签中。“布局”提供恢复默认布局、动画布局、专注画布。画布下方“动画编辑与时间轴”按钮打开/关闭独立时间轴，进入录制或添加轨道也会自动打开。

当前布局自动保存在当前浏览器；可在“布局”中输入名称并“保存当前布局”，最多12套，同名覆盖，再从“已保存布局”选择并“应用布局”或删除。布局只保存面板位置、比例、标签与显示状态，不保存节点、参数或动画，不进入项目 ZIP，不随项目分享，不跨浏览器/地址同步。切换或恢复布局不清空画布、左侧图库或撤销记录。

顶栏“组合示例”自动展示多种可编辑组合，卡片说明使用的排列、组合或动画方法，点“在画布中编辑”打开独立画布进行拆解。前五项为刀光拖尾、命中爆闪、破碎冲击环、能量旋涡、溶解遮罩。卡片为静态快照，打开后播放查看动画；单次效果关闭循环导出，旋涡开启循环，溶解遮罩默认高度输出且不透明。每个示例的时长、帧数、输出模式与透明设置随打开链接保留。四种 UI 底纹（菱形格纹、交错菱砖、斜纹底纹、点阵底纹）采用跨边缘重复的规则网格，默认不透明颜色 PNG；可改行列数、图形颜色和线宽，用“平铺检查”复核接缝。在预览区将画布背景设为透明可只导出纹样，供项目叠加底色。

## 统一图库与画布实例

左侧图库是紧凑视图，管理窗口是同一批资源的完整管理界面。内置、本地与远程资源直接显示，不需要“添加到左侧图库”。首次默认显示全部资源，之后记住筛选；收藏和最近使用保存在当前浏览器。远程资源使用时临时读取，点击“下载”才持久保存并支持离线使用。

图库资源与画布实例是两个层级。点“＋ 添加”或“直接添加到画布”创建独立实例；点缩略图或“试编辑”临时编辑。个人资源的“保存更改”发布新版本；“另存为新资源”保存独立结果。内置与远程资源的修改另存为个人资源。保存、改名、删除图库资源都不改已有画布实例。

“创建资源”提供图片、导入文件、公式和生成器。保存或导入成功后即出现在左侧；选中资源可批量导出完整ZIP及依赖。个人资源可重命名或删除；删除个人资源会清理其资源包、缩略图和历史版本，其他条目仍在引用的文件保留。图库文件夹的“清理未使用文件”先展示残留清单，确认后才删除；失败可重试，已有画布保持独立副本。画布的撤销只影响画布，不回滚图库版本。

旧版列表中未修改的副本复用图库原件；个人参数、颜色、效果、关键帧、组合或名称不同的条目迁成独立资源，保留来源与收藏。迁移失败的条目保留预览与重试入口，原始列表及依赖不删除。迁移完成后不再维护独立列表。

## 节点与画布

- “＋组合”创建容器，“添加顶层节点”可将现有顶层内容放入一个组合，再整体变换。图形可以独立编辑；组合排列默认重复整个子树，也可在“变换/排列 → 实例内容”选择“随机一个子节点”，每个位置从已启用的直接子节点中等概率选一个，允许重复。改变“杂排种子”重新选择（与高级排列种子共用）；动画/刷新/导出不会自行重选，动画暂时隐藏的候选仍保留原位置，遮罩不参与抽选。“展开为独立节点”保留当前抽选结果。
- 节点树顺序影响合成；拖拽中间改父级、上下边缘改排序。遮罩只影响同组排在它前面的内容。
- 单击选择；Ctrl/Cmd多选、Shift连选，空白框选；多选保留“图形（含颜色）/ 变换/排列 / 动画 / 合成”页签。共有参数可批改：显示、配色/透明度/渐变色标、位置/大小/轴心/镜像、排列与变化、混合/轮廓/后处理/滤镜、父级时间范围/循环/固定进度/参数动画开关。不同值显示“多个值”，复选框呈混合态；只覆盖调整的参数，可“编辑主选节点 / 返回批量编辑”。同一种图形可批改专属参数，混选不冒用主选图形的参数；UV和极坐标需要全选图形，内置运动设置需全选支持时间的图形。父子同时选中只修改最外层，避免叠加两次。
- 批改颜色不自动覆盖配色模式和色标。先统一“自定义配色”再编辑纯色/渐变；选择预设才统一替换色标。色标数量相同可逐个批改，不同可先应用预设或恢复各自双色。组合独立配色子节点和父级整体调色按原规则生效。宽高保留各自锁定比例，任一节点超限则整次取消。普通模式任一目标字段被动画控制则锁定；录制在各节点局部进度记关键帧，基础值保留动画。关键帧、数值曲线、时间重映射曲线仍从主选节点单独编辑，多色色标不录制关键帧。一次连续滑动形成一条撤销记录，保存/导出保留结果。
- 组合专属配色、沿图形轮廓、规则拼接需全选组合；混选时选项禁用并解释。排列方式或密度图案不同先统一类型再编辑对应参数。各组合保留自己的子节点，不自动创建来源或候选；图块接口通过选择实际子图块批改。
- 批量面板“对齐与分布”按旋转后的节点区域外框对齐，可选“所选范围”或“画布”。三个及以上节点支持水平/垂直等边缘间距，固定两端位置，空间不足允许重叠；不按不透明像素裁边。跨父级的独立可见节点也可对齐；隐藏或父级排列产生多个副本时禁用并说明原因，应选外层组合。
- 画布可拖移、缩放、旋转；双击组合进入、路径导航返回；Alt单击切换重叠节点，右键查看候选。Shift移动锁轴/旋转按15°吸附，Alt拖动临时关闭吸附。轴心和UV有独立工具。
- Ctrl/Cmd+D复制、Ctrl/Cmd+G组合同级节点、Delete删除；Ctrl+Z撤销，Ctrl+Shift+Z重做。拖动可Esc取消；Space临时平移视图。
- “显示 → 画布背景”统一选择透明（棋盘格）或纯色，可选颜色并用黑白快捷色，随项目保存并用于颜色预览和导出。打开完整项目采用其背景；插入组件保留目标画布设置，包括空画布。查看缩放、节点区域、轴心、单独预览和平铺仍仅用于查看，不改变导出尺寸。
- “平铺检查”旁的“平铺数量”提供2×2、3×3、4×4；选预设自动开启，关闭再开保留所选数量。它只显示重复边界，不改项目或导出尺寸，不能自动消除接缝。

画布比例可从预览顶部“比例”或“画布设置”选择预设或“自定义…”，宽高表示比例，支持1:8～8:1，不是导出像素数。已是自定义时可点旁边编辑按钮或再次选“自定义…”修改；只有“应用比例”才生效。切换/重置试编辑图形、返回或添加到画布均保留当前比例。

预览下方依次有选择、轴心、UV、平移、吸附，另一组是查看缩放、视图归位、显示、平铺。“平移视图”在适应窗口和缩小时也可从预览空白处拖动，Space 临时平移；“视图归位”适应并居中，各试编辑会话保留独立观看偏移。背景、节点区域、轴心放在“显示”菜单；平铺箭头选数量。平移和查看缩放不移动节点、不改 UV/关键帧，导出始终使用完整画布。

节点名称可双击或 F2 行内编辑，Enter 保存、Esc 取消；右侧垃圾桶只删除对应节点（组合包含子节点），可撤销。拖到图形中央时显示不修改作品的虚拟组合，说明普通节点只能放入组合；松开确认创建，移开或 Esc 取消。预览不接收鼠标事件或挤动列表。已有组合直接接受中央拖放；行边缘调整排序，禁止循环嵌套。

## 图形参数

图形和颜色统一在“图形”页签。图形选择、图形专属参数、UV、透明度、节点颜色、色阶、反相和通道曲线各自是可折叠模块，问号说明与展开独立。拖动标题旁手柄排序，也可聚焦手柄后按键盘上下键；展开状态和顺序保存在当前浏览器，按页签跨节点、语言和刷新保留，不写入作品、不改变处理顺序，也不进入撤销。

“配色”使用下拉框，“着色方式”使用纯色/数值渐变分段控件。点击渐变条添加采样色标，拖动调整位置，选中色标修改颜色、HEX 或位置；支持2～8个色标、删除、内置渐变下拉预设、反转渐变、恢复双色。HEX 接受3位或6位，可省略#。反转渐变只镜像色标位置；节点“反相”反转明暗/高度并可能影响派生透明度。

“透明度”模块使用0～1，影响整个节点/组合，父子透明度相乘。支持录制、基础值、撤销和保存；普通模式下动画控制的字段禁用。顶部不再提供独立颜色快捷区。

继承配色时显示“继承自：组合名”，可“前往来源”编辑父级，或“改为独立配色”复制当前求值后的配色到此节点，保持起始外观，随后独立修改。组合保留子节点颜色时，节点颜色模块提供“为子节点设置配色”；已有独立配色的子节点保持原样。上层“组合统一配色”会在合成后重新映射颜色，即使子节点独立配色也会受影响，界面提示来源并可跳转。图片原色和生成器原色显示原色状态，“自定义着色”会按亮度重新映射，不能承诺保持原图颜色。

双色渐变的暗部/亮部颜色与纯色填充可录制关键帧，普通模式下动画控制的颜色输入禁用，按进度同步色块。多色色标不支持关键帧，恢复双色渐变取当前最左/最右色标作为端点，再提供端点颜色关键帧。应用预设和增加/删除色标修改项目的基础渐变，不能当成颜色动画。

组合“实例内容”支持整个组合、随机一个子节点、按顺序循环（取模）。防堆叠、额外间距、铺满区域、实例比例和展开编辑的操作与限制见[排列与合成](layout-compositing.md)。排列节点“实例比例”控制每份内容；节点“区域适配”控制这一整个节点，调整前先确认目标范围。

“图形”页选择基础图形、编辑名称/显示状态和专属参数。基础图形下拉通常仅包含已加载到画布的图形及当前图形；可从左侧图库直接添加所需资源到画布。
查用户导出的 AI 图形目录确认当前资源名称、参数范围与动画能力。参数随图形或模式显示，例如齿轮不同齿形、星形不同轮廓会出现不同参数。不要把另一个图形的参数照搬过来。
“重置图形参数”恢复默认，“随机参数”用于探索，不适合作为确定复刻步骤。羽化0仍有抗锯齿，增加羽化主动软化边缘；新节点默认清晰，而资源内已有羽化设置会保留。

## 保存与分享

“保存项目”保存当前画布ZIP及依赖，“打开项目”恢复；草稿自动保存不能代替备份。含自定义资源或离线打开时“分享配置”会转为项目文件；简单内置画布可生成带配置的链接。

图库独立于画布：打开或新建项目不改变图库。项目ZIP只包含画布及依赖；整个图库通过资源ZIP或绑定文件夹保存。旧列表的个人修改会迁成独立资源，原始记录保留。
个人资源只来自当前绑定的本地图库文件夹，换绑后列表随之更新，不自动复制或合并原图库。创建与保存前先检查绑定和权限。启动检测到旧浏览器资源时弹窗引导绑定，自动保存并回读校验后清理旧浏览器资源和旧列表；失败保留尚未迁移的原数据，可重试。关闭图库不改变磁盘文件或已有画布。
“保存整个画布到图形库”存成一个可复用组合；保存选中节点只保存该节点及其子树。导出PNG/SVG等是制作交付文件，不是可完整恢复编辑状态的项目存档。

## 多地址远程图库

订阅、保存和离线使用，或管理、发布自己的图库时，阅读[远程图库使用与管理](remote-libraries.md)。其中区分订阅目录、当前图库文件夹与画布实例，并给出同ID卡片、更新/删除范围、纯静态管理器及Git/Pages/CDN发布的步骤和排错。

## 滤镜与材质预览

节点“合成”页的“后处理：亮度、色阶与反相”中增加模糊、Bloom、锐化、色散和卡通色阶，支持关键帧。半径按512像素画布计。组合先合成子节点再处理。合成预览的“贴图类型”切换法线后可调整法线强度、Sobel/Scharr、翻转X/Y、反转高度、预平滑；自定义RGBA中的法线通道也使用这些设置。原色图片的亮度作为高度，因此不透明图片内部的明暗细节也能生成法线。生成参数保存到项目，导出法线时使用同一组参数。法线强度和预平滑以画布短边 512 像素为基准，不随交互／高清预览或导出采样尺寸改变强度尺度；细节清晰度仍受实际采样尺寸限制。

合成预览标题旁的“贴图类型”选择颜色、高度、法线或自定义RGBA，“预览模式”切换二维画布与三维材质。二维法线显示可导出的蓝紫色法线图；三维法线用中性材质展示实际生成法线的受光效果，颜色模式显示平贴花纹，高度模式显示灰度。三维可选球体、平面、立方体，跟随参数修改、进度拖动与动画播放实时更新；支持拖动旋转、灯光、粗糙度、金属度与纹理重复，切回二维恢复画布操控。贴图类型切换只改变查看方式；导出面板中要单独选择“输出内容 → 法线”，导出的始终是平面贴图。灯光、模型和视角设置不写入导出图片。

## 参数状态提示

“动画控制中”表示普通模式下参数和复位按钮由轨道控制。参数旁可直接点“录制修改”调整当前时刻的关键帧，或“编辑基础值”调整基础状态；退出模式后恢复动画求值。暂停轨道或关闭本节点参数动画后不再锁定。

“当前不生效”说明依赖条件尚未满足，数值仍保留：烟气混合/密度为0、UV滚动速度为0或轮廓方式关闭时，相关参数旁会提示先调整哪个开关。提示使用当前动画求值。沿图形轮廓与规则拼接的选项在单图形上标为“需组合”，参数区说明需先创建组合并放入来源或候选图块。

## 特效混合预览

画布上方“预览模式 → 特效预览”把当前贴图类型的透明结果放到背景上，通常先选颜色。背景有深色、浅色、深浅对照、自定义；混合可选透明、相加或两者并排。透明保留遮挡，相加使用颜色乘透明度后叠亮。深浅对照加混合对照共四格，所有格共用同一帧采样。

原有播放、重新播放、进度与关键帧时间轴继续控制动画，右侧参数仍可编辑；画布拖动与UV操作暂停，切回二维画布恢复。“显示大小”20%～100%、“预览亮度”0～3倍仅改变观看，复位恢复默认深色、透明/相加对照、80%大小和1倍亮度。背景和混合也只是视图设置，不保存到项目、不参与PNG或序列导出、不改变节点混合或导出透明度。实际项目的HDR、色彩空间和材质需在引擎内确认。

## 参数显示语言

右上角的语言下拉框可直接选择简体中文或 English，选择后立即生效，无需弹窗或确认。用户不能手输语言编码或增加、排序语言类型；参数先查找所选语言的别名，再按构建配置顺序回退，全无匹配时显示变量名。内置参数带中英文别名，第三方图形可只提供一种语言。悬停参数可查变量名；指导用户时同时提供别名与变量名，不能把显示名称当作公式或关键帧绑定。语言偏好不改变项目或资源。创建/编辑图形时可展开“多语言别名 / Aliases”，从固定下拉框选择语言并填写别名；语言类型来自编译时配置，不能手输或重复添加。

界面固定文案支持简体中文与英文，语言偏好也影响图库、预览、导出、时间轴、布局、示例与内置说明；资源已有的未启用语言别名会保留，但不参与当前构建的选择和回退。指导时使用用户当前界面语言的入口名称，并提供参数变量名便于定位。用户自定义的项目名、节点名与代码保留原文，图形资源默认名保留原文、显示名按资源别名解析，不把这些文字误判为翻译遗漏。

界面文案的内部消息 key 与资源参数别名相互独立。指导用户填写别名时应填写实际名称（如“半径”或“Radius”），不要填写 menu.file 这类界面消息 key；语言切换不会改变资源定义。


图形名称旁的“多语言名称”允许从固定语言下拉框添加名称别名。内置与用户图形采用相同格式，图形库、左侧图库和远程目录都会按当前语言优先显示；未匹配时用默认名称。搜索覆盖默认名称、所有语言别名与ID。别名随资源、创作JSON及ZIP保存，组合发布和左侧图库重命名也支持。新节点使用当时的显示名作为初始名称，之后节点名独立保存；切换语言不改已有节点。

左侧与管理窗口直接显示当前可用的内置、本地和远程资源，无需初始化常用副本；创建或导入后立即可用。

缩略图网格按面板可用宽度自动增加或减少列数，卡片最小宽度约120px；加宽面板可显示三列、四列或更多，窄面板会退为一列。“浏览方式 → 列表”继续使用单列。

节点后处理的效果顺序保存在节点内，会改变真实渲染；它与仅整理界面的模块顺序不同。整体处理请使用外层组合，详见[排列与合成](layout-compositing.md)。
