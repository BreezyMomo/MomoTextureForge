# 界面与资源管理

## 主界面

- 顶栏左侧为画布名称，可直接修改。中间为当前画布操作：文件（新建画布、打开项目、保存项目、分享配置）、撤销/重做、画布设置、导出。右侧为工具入口：图形库、组合示例、帮助、布局。帮助菜单包含使用说明、直达 README 与图文教程的“详细说明”、下载创作Skill、下载效果指导Skill，以及在新标签页打开的“GitHub 仓库”链接（查看源码、反馈问题或参与贡献）；两个Skill下载均为ZIP，将解压后的文件夹交给支持Skill的AI。
- 左侧：节点树与图形列表。中间：画布预览、画布工具与动画播放。右侧：当前主选节点的“图形 / 变换/排列 / 动画 / 合成”。未选节点时没有这些参数。
- 预览右上角：保存选中节点到图形库、保存整个画布到图形库、另存到图形列表、更新到图形列表（有关联资源时）、单独预览。名称相近但保存范围不同。

## 自定义面板布局

节点树、图形列表、画布预览、参数面板、时间轴可分别停靠。上述左右位置指默认布局；用户可拖动面板顶部标签改变位置。拖到另一个面板边缘出现蓝色提示后松开，可上下/左右拆分；拖到中央合并为标签，点击标签切换。拖动两面板之间的分隔线改变比例。

面板右上角“↗”在网页内悬浮当前标签；Alt 拖动标签也可悬浮。悬浮窗口左上角握柄移动，右下角握柄缩放；将标签拖回其他面板即可停靠。悬浮不创建独立浏览器窗口。拖动中按 Esc 取消。

右上角“×”关闭当前面板，内容保留；从顶部“布局”菜单勾选名称重新打开。找不到参数或时间轴时先检查面板是否关闭或位于其他标签中。“布局”提供恢复默认布局、动画布局、专注画布。画布下方“动画编辑与时间轴”按钮打开/关闭独立时间轴，进入录制或添加轨道也会自动打开。

当前布局自动保存在当前浏览器；可在“布局”中输入名称并“保存当前布局”，最多12套，同名覆盖，再从“已保存布局”选择并“应用布局”或删除。布局只保存面板位置、比例、标签与显示状态，不保存节点、参数或动画，不进入项目 ZIP，不随项目分享，不跨浏览器/地址同步。切换或恢复布局不清空画布、图形列表或撤销记录。

顶栏“组合示例”自动展示多种可编辑组合，卡片说明使用的排列、组合或动画方法，点“在画布中编辑”打开独立画布进行拆解。前五项为刀光拖尾、命中爆闪、破碎冲击环、能量旋涡、溶解遮罩。卡片为静态快照，打开后播放查看动画；单次效果关闭循环导出，旋涡开启循环，溶解遮罩默认高度输出且不透明。每个示例的时长、帧数、输出模式与透明设置随打开链接保留。四种 UI 底纹（菱形格纹、交错菱砖、斜纹底纹、点阵底纹）采用跨边缘重复的规则网格，默认不透明颜色 PNG；可改行列数、图形颜色和线宽，用“平铺检查”复核接缝。开启导出透明背景可只导出纹样，供项目叠加底色。

## 三层资源与版本

| 位置 | 用途 | 修改/删除影响 |
| --- | --- | --- |
| 本地图形库 | 可重复使用的公式、图片、组合资源 | 包含内置、本地原创和多地址远程来源；远程是静态目录订阅，无账号或服务端发布权限；删除自建库资源会删除库内资源 |
| 图形列表 | 当前浏览器中跨画布常驻的常用资源副本 | 从图库或手动保存加入；新建/打开画布不清空、不自动接收项目资源；手动移除不删图库原件 |
| 画布节点实例 | 画布中真正绘制的内容 | 调整实例不自动改图库或其他实例；更新到图形列表是明确动作 |

图库可搜索名称/分类/标签，筛选内置/我的/公式/图片/组合，支持全选当前结果、取消选择、批量添加和导出勾选资源。已有旧版本可显示“有新版本 · 更新”，更新图库/列表不要解释成全局替换所有实例。
资源包含全局资源ID、版本ID、个人修改次数。更新图形列表中的本地副本增加个人修改次数；发布资源新版本提升版本并重置个人修改计数。重新导入ID相同但内容变化的资源可能提示作为新资源导入，不让用户手改ID解决冲突。

图库“创建资源”进入图片/导入文件/公式/生成器四个页签；“导出资源”导出勾选项ZIP，包含资源及依赖，不只是截图。生成器页接受自定义GLSL与多步骤渲染JSON，已有生成器可编辑参数后另存。内置图形的编辑通常另存为自己的资源；自建图形编辑器可更新原图形。删除操作需说明范围，不代执行。

图形列表卡片“＋ 添加”创建画布实例。点缩略图进入试编辑；“添加到画布”才插入实例，“返回画布”回原画布。“更新到图形列表”覆盖该列表项，已有实例保持原样；更新后可“撤销更新”。“另存到图形列表”建立新条目。

当前节点没有有效关联条目时，预览上方显示“保存到图形列表”；有对应条目时提供“更新到图形列表”和“另存到图形列表”。保存会让用户填写名称；整个画布默认使用画布名称。删除关联条目后更新入口隐藏，画布内容保留，可重新保存；撤销删除可恢复关联。卡片“更多 → 重命名”修改该列表条目及以后添加的组件名称，已有画布实例名称和本地图形库保持原样；名称需1～80个字符，取消不修改。列表及改名独立自动保存，可以撤销/重做；画布操作的撤销不会重置列表。

## 节点与画布

- “＋组合”创建容器，“添加顶层节点”可将现有顶层内容放入一个组合，再整体变换。图形可以独立编辑；组合排列默认重复整个子树，也可在“变换/排列 → 实例内容”选择“随机一个子节点”，每个位置从已启用的直接子节点中等概率选一个，允许重复。改变“杂排种子”重新选择（与高级排列种子共用）；动画/刷新/导出不会自行重选，动画暂时隐藏的候选仍保留原位置，遮罩不参与抽选。“展开为独立节点”保留当前抽选结果。
- 节点树顺序影响合成；拖拽中间改父级、上下边缘改排序。遮罩只影响同组排在它前面的内容。
- 单击选择；Ctrl/Cmd多选、Shift连选，空白框选；多选时右侧编辑主选节点，画布移动与工具栏操作作用于选中集合，不宣称所有参数会同时批改。
- 画布可拖移、缩放、旋转；双击组合进入、路径导航返回；Alt单击切换重叠节点，右键查看候选。Shift移动锁轴/旋转按15°吸附，Alt拖动临时关闭吸附。轴心和UV有独立工具。
- Ctrl/Cmd+D复制、Ctrl/Cmd+G组合同级节点、Delete删除；Ctrl+Z撤销，Ctrl+Shift+Z重做。拖动可Esc取消；Space临时平移视图。
- “查看缩放”、棋盘格/黑色/白色背景、节点区域、显示轴心、单独预览均为查看辅助。导出整个画布不包含辅助线，也不按查看缩放改变像素尺寸。画布输出背景需在导出/画布设置中配置。
- “平铺检查”显示画布重复边界，只用于观察，不能自动消除接缝。

## 图形参数

组合“实例内容”支持整个组合、随机一个子节点、按顺序循环（取模）。防堆叠、额外间距、铺满区域、实例比例和展开编辑的操作与限制见[排列与合成](layout-compositing.md)。排列节点“实例比例”控制每份内容；节点“区域适配”控制这一整个节点，调整前先确认目标范围。

“图形”页选择基础图形、编辑名称/显示状态和专属参数。基础图形下拉通常仅包含已加载到画布的图形及当前图形；找不到先从图库添加到图形列表。
查用户导出的 AI 图形目录确认当前资源名称、参数范围与动画能力。参数随图形或模式显示，例如齿轮不同齿形、星形不同轮廓会出现不同参数。不要把另一个图形的参数照搬过来。
“重置图形参数”恢复默认，“随机参数”用于探索，不适合作为确定复刻步骤。羽化0仍有抗锯齿，增加羽化主动软化边缘；新节点默认清晰，而资源内已有羽化设置会保留。

## 保存与分享

“保存项目”保存当前画布ZIP及依赖，“打开项目”恢复；草稿自动保存不能代替备份。含自定义资源或离线打开时“分享配置”会转为项目文件；简单内置画布可生成带配置的链接。

图形列表独立于画布：新建/打开项目、打开分享配置和刷新不会清空当前列表。打开项目只恢复画布与所需资源，不自动把这些资源加入列表；需要常用项时手动保存。项目ZIP也只携带画布依赖，不打包整个列表，不作为常用列表备份。旧版当前草稿中的列表会在首次升级时迁移；已有独立列表（包括手动清空后的空列表）优先。列表保存在当前浏览器与工具地址下，不跨设备/域名自动同步；要转移某项，可将它保存到图形库后导出资源。
“保存整个画布到图形库”存成一个可复用组合；保存选中节点只保存该节点及其子树。导出PNG/SVG等是制作交付文件，不是可完整恢复编辑状态的项目存档。

## 多地址远程图库

使用地址订阅、下载和离线使用，或管理、发布自己的图库时，阅读[远程图库使用与管理](remote-libraries.md)。其中区分订阅目录、远程缓存、浏览器本地图形库、图形列表与电脑图库文件夹，并给出同ID卡片、更新/删除范围、纯静态管理器及Git/Pages/CDN发布的具体步骤和排错。

## 滤镜与材质预览

节点“合成”页的“后处理：亮度、色阶与反相”中增加模糊、Bloom、锐化、色散和卡通色阶，支持关键帧。半径按512像素画布计。组合先合成子节点再处理。合成预览的“贴图类型”切换法线后可调整法线强度、Sobel/Scharr、翻转X/Y、反转高度、预平滑；自定义RGBA中的法线通道也使用这些设置。原色图片的亮度作为高度，因此不透明图片内部的明暗细节也能生成法线。生成参数保存到项目，导出法线时使用同一组参数。法线强度和预平滑以画布短边 512 像素为基准，不随交互／高清预览或导出采样尺寸改变强度尺度；细节清晰度仍受实际采样尺寸限制。

合成预览标题旁的“贴图类型”选择颜色、高度、法线或自定义RGBA，“预览模式”切换二维画布与三维材质。二维法线显示可导出的蓝紫色法线图；三维法线用中性材质展示实际生成法线的受光效果，颜色模式显示平贴花纹，高度模式显示灰度。三维可选球体、平面、立方体，跟随参数修改、进度拖动与动画播放实时更新；支持拖动旋转、灯光、粗糙度、金属度与纹理重复，切回二维恢复画布操控。贴图类型切换只改变查看方式；导出面板中要单独选择“输出内容 → 法线”，导出的始终是平面贴图。灯光、模型和视角设置不写入导出图片。
