## 节点级排列选项

这些选项不在上面的公共数值数组中，按节点和排列方式显示；完整语义见[排列与合成](layout-compositing.md)。

| 选项 | 默认 | 可选值/范围 |
| --- | --- | --- |
| 实例内容（组合且开启排列） | 整个组合 | 整个组合 / 随机一个子节点 / 按顺序循环（取模） |
| 杂排种子（随机子节点） | 与排列种子共用 | 1～999，步长1 |
| 实例比例（开启排列） | 保持设计比例 | 保持设计比例 / 随区域拉伸；旧项目缺省也保持设计比例 |
| 防堆叠（随机散布） | 关闭 | 开启 / 关闭；整个区域与密度图案均可用 |
| 额外间距（防堆叠开启时） | 0 | 0～0.5，步长0.005；按区域短边尺度 |

铺满区域不是新的范围模式：将现有布局半径设为0.5、中心偏移归零，保留其他设置。数量是目标值，防堆叠和密度限制可使实际数量更少。
