# 远程图库使用与管理

<!-- doc-language -->
[简体中文](remote-libraries.md) · [English](remote-libraries.en.md)
<!-- /doc-language -->

按用户目的选择流程：使用别人提供的地址看“订阅与使用”；整理自己的资源看“纯静态管理器”；让其他人订阅看“手动发布”。本Skill仅指导用户操作，不代点击、读写目录、上传或执行Git命令。

## 先区分资源放在哪里

| 内容 | 保存位置与用途 |
| --- | --- |
| 远程图库 | 服务器上的index.json、资源ZIP和缩略图，供订阅下载 |
| 远程下载缓存 | 当前浏览器缓存，下载后可离线使用，来源仍是远程 |
| 本地图形库 | 当前浏览器中的独立资源，不是电脑上的Git仓库文件夹 |
| 图形列表与画布 | 编辑器中使用的个人副本与实例，不被远程缓存自动更新 |
| 管理器选中的本地目录 | 下载/克隆的图库文件夹，修改后需用户另行发布 |

“下载到本地”不代表写进Git仓库，也不代表另存为自己的新图形。图形列表、订阅和缓存按浏览器及编辑器地址保存，不自动跨电脑同步。项目携带实际使用的依赖，不备份整套订阅或下载缓存。

## 订阅与使用

1. 在编辑器顶栏打开“图形库”，展开“资源管理”，点击“远程图库”。
2. 填“新图库名称”和“远程目录地址”，点击“添加订阅”。地址应指向发布者给出的index.json，例如 `https://example.com/library/index.json`（仅为格式示例，不是实际图库）。以 `/` 结尾时会补index.json；Git仓库首页、ZIP下载链接和library.json都不是订阅目录。
3. 看到“远程图库已连接”后关闭订阅窗口，在“资源来源”选择该图库。可添加多个地址，各自启用、停用、改名、刷新或移除。
4. 找到资源，点击“下载到本地”只缓存；点击“添加到图形列表”会按需下载并添加。要在画布使用，再点左侧图形列表卡片的“＋ 添加”。
5. 下载后可离线使用。未下载项只有目录信息与缩略图，首次添加、编辑或导出资源包仍需要联网。远程公式/图片的编辑另存新资源，不直接改远程包。

手动更新目录可在订阅窗口点击“立即刷新”，或在图形库点击“刷新远程图库”。自动检查默认开启，仅在图形库打开时按五分钟间隔检查，不是服务端实时推送。

## 来源合并、版本与更新

同资源ID只显示一张卡片；顶部来源、下载状态描述当前操作对象。“全部来源与版本”列出本地/内置/多个远程来源，“使用的来源与版本”决定添加、编辑、导出和删除哪个版本。默认本地优先，其次内置，否则选择最新远程；来源筛选限制可选对象。切换对象会取消该资源原勾选，批量操作每个ID只处理当前对象。

| 入口或状态 | 实际影响 |
| --- | --- |
| 本地已有 · 内容一致 | 同ID同版本的已知校验值一致，浏览时合并，存储仍独立 |
| 远程有新版 / 本地版本较新 | 提示版本高低，不自动覆盖本地图形 |
| 内容待核对 / 内容冲突 | 缺少校验值不能断言一致；同版本不同内容不能强行覆盖 |
| 自动下载已下载资源的新版 | 默认关闭；开启后只更新已缓存资源，可跨版本，不下载整个库 |
| 更新本地版本 | 经确认把远程新版保存到本地图形库，不改图形列表或画布 |
| 有新版本 · 更新 | 经确认更新图形列表项，会替换其个人修改，已有画布实例不变 |

开启自动下载需在订阅窗口勾选后点“保存设置”。不要把“缓存已更新”“本地图形库已更新”“图形列表已更新”“画布实例已改变”混为一谈。个人修改要共享时应另存独立资源并自行发布，编辑器不会自动上传。

## 删除与停用的范围

- “移除订阅”或取消“启用此图库”：保留下载缓存、图形列表和画布。仍可从“已下载远程资源”找到缓存；修改地址会清除旧目录身份，旧下载仍保留。
- 远程卡片“删除本地下载”：确认后清除此来源、此资源的所有下载版本，不删其他来源、独立本地图形、列表或画布。有效订阅恢复“未下载”；已停用/移除源的缓存卡片可能消失，需恢复订阅才能再次下载。清除后停止跟踪此资源自动新版下载，手动下载后恢复。
- 选择本地来源后“删除资源”：删除本地图形库条目；若还有远程来源，合并卡片会保留。不要误称为删除远程服务器文件。
- 静态管理器“移出目录”：从所选电脑文件夹的index.json下架条目，保留ZIP/缩略图。远程目录要等用户发布后才改变；旧下载链接与已经缓存的副本不会因此立即消失。

## 纯静态管理器：整理自己的图库

准备下载/克隆的图库文件夹，其中有index.json、resources/、thumbnails/及随包管理器。没有Git并不妨碍文件管理；要手动提交推送时才需要Git仓库与相应权限。

1. 用新版桌面Chrome或Edge打开根目录“library-manager.html”，也可通过HTTPS访问manager/index.html。无需Node.js、npm、EXE或本地服务。
2. 点击“选择本地图库目录”，选中图库根文件夹并授权读写。首次必须选择目录并授权；之后在当前浏览器记住目录，已有读写权限时刷新或重开会自动恢复，否则点“继续使用”授权，不必重新找目录。“关闭图库”会忘记上次目录，但不清除恢复快照。不支持的浏览器或安全上下文会显示提示，不建议禁用安全保护。
3. 从编辑器图形库勾选资源并“导出资源”，得到正式单资源或合集ZIP。回管理器点“导入资源ZIP”，检查新增/更新预览，再“确认导入”。每次最多32个ZIP、合计64MB；不能直接用任意PNG/SVG、项目ZIP或Skill ZIP代替正式资源包。
4. “编辑信息”修改目录中的名称、分类、标签和说明；“修改图库名称”修改整库展示名。只改index.json，ZIP内容、资源ID、版本与校验值不变。要改图形内容，先在编辑器制作并导出正式新版；同ID同版本不同内容会被拒绝。
5. 勾选资源后“移出目录”可批量下架，旧文件保留。需要同时删除文件时使用“彻底删除”，确认影响后再执行。“彻底删除”会移除所选目录条目并删除当前引用的 ZIP 和缩略图，共用文件保留；历史版本和此前移出目录的文件不自动清理。删除前需确认，旧项目下载可能受影响，目录快照/JSON 不能恢复已删除文件。先保存目录再清理文件；清理失败会列出未删除路径，需检查权限后手动清理。本地删除要自行发布后才影响远程，浏览器已有缓存不受本地删除直接影响。不会修改未选择的其他目录，不操作.git，也不上传文件。
6. 需要撤销目录变化时打开“目录恢复”。每次修改前自动在当前浏览器保存最多50份快照，按图库ID和页面来源隔离，不写进资源仓库。清理浏览器数据、换浏览器/来源可能失去原快照；重要备份点击“下载当前目录备份”，以后可“恢复JSON备份”。恢复会检查图库身份及引用ZIP是否仍在、哈希是否匹配。

管理器从线上打开时仍只修改访问者授权的本地目录，不能因此修改服务器资源。无缩略图时显示占位符，不会自动渲染公式。避免同时用其他程序修改目录；遇到“目录已被其他窗口或程序修改”，刷新目录后核对结果，权限失效时先点击“继续使用”授权，再重新操作，不建议覆盖旧修订。

## 手动发布：Git、Pages或CDN

管理器保存完成不代表已经发布。先检查本地变更，确认index.json仍引用完整ZIP/缩略图，保持libraryId以及已发布资源ID/版本对应的不可变内容，再按用户实际部署方式指导：

| 方式 | 用户需要完成的动作 |
| --- | --- |
| Git仓库 | 提交并推送修改。普通Git服务器只保存仓库；推送成功不等于目录已作为网站上线 |
| GitHub Pages / 已配置的GitLab Pages | 推送到实际发布分支/目录，等待部署完成，核对公开index.json地址。不要假定所有Git平台自带Pages |
| CDN / 静态网站 / 对象存储 | 上传到实际站点目录，先资源与缩略图，最后index.json；目录使用合适的短缓存/重新验证或刷新缓存，新版本资源使用新文件名 |

整个纯静态管理器可随包发布，无需线上写入后台；授权仅针对访问者本地文件。发布文件不要携带远程上传凭据。读取端需要可访问的HTTP(S)地址和跨域许可；HTTPS编辑器应使用HTTPS图库。仅有浏览器登录态或Git权限不代表编辑器能读取私有下载地址。

发布后检查：index.json可直接读取、资源与缩略图地址正确、跨域访问允许；回编辑器刷新订阅，下载一项实际新增/更新资源验证。新图库可让用户绑定 `<发布目录>/index.json`；更新已有库通常继续使用原地址。只改CDN域名或迁移地址时也应保留图库身份。

首次生成静态图库、缺少随包管理器时，开发者可使用工具仓库的 `build-remote-library.mjs`（正式ZIP→静态目录，自动带管理器），或 `build-library-manager.mjs`（给现有目录补管理器）。这是开发端构建工具，需要Node与开发依赖；最终管理器使用者不需要。指导Skill只解释现有工具，不假定这些脚本已经安装在用户电脑或已经代其部署。

## 常见问题

| 现象 | 优先核对 |
| --- | --- |
| Failed to fetch / 无法读取远程图库 | index.json地址是否为直接文件地址、网络、HTTPS混合内容、跨域响应头；浏览器能打开首页不证明跨域资源读取可用 |
| 目录已刷新但旧图形没变 | 检查更新的是目录、缓存、本地图形库、列表还是画布；用对应明确更新入口 |
| 同ID同版本内容不同 / SHA-256失败 | 资源包是否被重新打包或覆盖、目录校验是否匹配；让发布者提供正确包或正式新版本，不改ID或关闭校验来绕过 |
| 导入提示缺少manifest.json | 是否误用了项目/Skill/普通图片合集ZIP；回编辑器“图形库→导出资源”取得正式包 |
| 管理器选择目录不可用 | 换用支持目录读写的新版桌面Chrome/Edge，检查安全上下文；从受限内嵌预览改为用户手动打开HTML或HTTPS管理页 |
| 刷新后目录没有自动打开 / 恢复记录没有了 | 已记住目录时点击“继续使用”授权；目录移动、主动关闭、清理浏览器数据或换来源可能需重选。快照也按浏览器与来源保存，必要时使用JSON备份 |

网络、跨域或校验失败会保留既有目录/下载缓存，单个源失败不影响其它图库。故障时先保留画布和已有资源，不建议清空浏览器存储作为第一步。
