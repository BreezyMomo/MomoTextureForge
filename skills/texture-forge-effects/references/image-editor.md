# 创建资源与图片处理

图库“创建资源”有图片、导入文件、公式、生成器四个页签，共用资源名称/分类/说明。预览成功后“导入图形库”，然后选资源添加到图形列表，再从列表添加到画布。两个AI Skill下载入口在主界面右上角，不在此窗口内。

## 图片页

图片添加为画布节点后，在右侧“图形 → 图片比例”默认“保持原图比例”：位图和SVG都在节点占用区域内部等比适配，宽画布不会将独立图片拉扁；旧项目缺省也使用此模式。“随区域拉伸”用于主动改变图片比例。该设置跟随节点和项目保存，不修改源图片、整组区域或排列覆盖范围；节点区域辅助框仍显示分配范围，不是可见轮廓。排列的“实例比例”和整个节点的“区域适配”是另外两层设置。

图形库卡片与批量导入条目会显示“位图”（PNG/JPG/WebP）或“矢量图（SVG）”，依据实际保存格式判断。位图转SVG并保存后属于矢量图；公式仍标记“公式”，不能把公式资源或普通PNG称为SVG矢量图。

上传PNG/JPG/WebP（最长边4096、单张16MB）或静态SVG（2MB）。SVG保留源文件，按渲染尺寸生成纹理；不支持脚本、外链、动画、CSS样式或文字，文字应转路径。SVG与位图可用的处理项不同，以下位图选项不会全部显示在SVG资源上。

图片页和已有图片编辑器支持Ctrl+V（macOS：⌘V）粘贴剪贴板实际图片，例如截图，载入后可继续处理和保存。普通文字仍粘贴到名称/说明字段，图片网址或只有HTML引用不会作为图片下载。浏览器未提供图片数据时使用文件选择。页面不会主动读取剪贴板或要求额外读取权限。

| 功能/配置 | 效果和操作提示 |
| --- | --- |
| 图片显示 | 原色与透明度保留图片颜色；亮度遮罩按亮度形成强度；透明度遮罩按alpha形成形状。遮罩模式用于节点配色；改色后亮度遮罩的强度也可能变化 |
| 缩放与旋转 | 缩放10%～400%，顺时针旋转−180～180°，围绕画布中心；画布不变，超边裁切，有重置按钮 |
| 剔除背景：保留原图 | 不做背景剔除 |
| 指定颜色去背景 | 选择/吸取背景色，用容差与边缘过渡控制匹配和柔边；只删除与边缘连通的背景可保留内部同色区域，取消则内部也参与，同色主体可能误删 |
| 提取指定颜色 | 在“颜色提取与背景处理 → 处理方式”中选择；设置“保留的颜色”或“吸取要保留的颜色”。整张位图的匹配色都会保留，其他颜色变透明，保留原RGB并乘上原透明度。容差扩大近似色范围，边缘过渡控制匹配边界；不按边缘连通筛选，不做背景反混色。PNG/JPG/WebP可用，可继续转SVG，SVG源文件不显示此位图处理项 |
| 黑底特效转透明 | 适合黑底亮纹/光效；黑色阈值与过渡控制淡边，需对比黑/白背景检查发黑残边 |
| 自动居中 | 按处理后非透明像素范围居中，不自动放大主体，也不改变画布尺寸 |
| 轮廓重建 | 对简单模糊轮廓重新整形，调相关阈值/过渡并对比；不能恢复照片纹理或凭空补出原图真实细节 |
| 调整颜色 | 不调整/统一着色/替换指定颜色；源色可取色，目标色设新颜色，容差/过渡决定匹配范围；保留半透明保留柔边，关闭后匹配可见像素趋向不透明，完全透明背景不填实 |
| 查看原图 | 对比原图和处理结果，右侧预览背景可切换棋盘格/黑/白；预览跟随滚动区域 |
| 转为SVG路径 | 从处理后的图片提取单色轮廓并保留孔洞；阈值筛选透明度，去毛刺减轻边界凹凸，平滑拟合曲线，细节保留与采样最长边平衡精度/点数。渐变、柔边与多色会简化 |

本次编辑草稿内可查看输入图片、关闭处理或重置变换进行对比。点击保存/导入图形库即确认：有处理的位图按输入图片原始像素尺寸生成最终透明PNG，只保存结果，去背景、居中、轮廓重建、颜色处理和图片缩放/旋转不再作为可恢复的处理记录携带；以后编辑以成品为起点。图片显示模式仍可改，节点的配色、区域、排列和动画保持可编辑。未处理的图片无需重复编码；SVG保留矢量路径。保存旧版项目也会在导出副本中固化旧位图处理，不改写已保存的旧文件或批量删除旧图库。

图片处理采用即时预览；复杂转换或保存固化仍需等候。预览失败会保留上一次成功画面，不代表新设置成功，先读状态再保存。保存失败不会以原图冒充处理结果。固化主要减少以后加载时的去背景/居中与采样处理，去背景原本也不是每帧执行；透明PNG不保证比原JPG更小。
路径很多可能变慢，50000锚点提示复杂度；超过2MB的SVG提示实际体积，需降低采样尺寸/细节或用位图。原图像素足够时保留位图往往更合理。复杂花型/精细修复先在PS编辑再上传；该工具不是完整图片编辑软件。

## 图片转高度与法线

1. 将图片添加到画布，保留“图形 → 图片显示 → 原色与透明度”。原色图片使用亮度乘透明度作为高度；透明区域高度为零，不透明图片内部明暗也能产生法线。
2. 画布顶部“贴图类型”选“高度”查看灰度，或选“法线”查看蓝紫色法线图。法线按相邻像素的高度差生成；照片的阴影也会被解释为高度，不会恢复真实三维结构。
3. 在预览区的法线生成参数中调强度、Sobel/Scharr、翻转X/Y、反转高度与预平滑。强度0产生平坦法线；“反转高度方向”交换凹凸，“翻转法线Y”可匹配使用端的法线方向约定。
4. “预览模式”选“三维材质”检查中性材质的受光，拖动旋转或调整灯光；切回“二维画布”检查实际法线图。颜色模式显示平贴花纹。
5. 导出面板单独选“输出内容 → 法线”，再选PNG或所需格式。生成参数与项目一起保存，原始图片仍保留颜色；预览贴图类型切换不会改动源图片或自动切换导出内容。

## 导入文件页

可选择一个或多个创作JSON，或粘贴创作JSON并解析。单项可预览编辑；多项先勾选，批量导入保留各资源名称和分类。ZIP只支持由工具“导出资源”生成、包含manifest.json及依赖的正式资源包/图形库包。普通JSON/预览合集ZIP需先解压再选JSON；AI Skill ZIP是技能包，不导入图形库。出现“缺少资源文件：manifest.json”时先确认包类型，不让用户补空清单。只解析不会自动发布；相同资源ID冲突时依据提示选择是否作为新资源保存。

## 公式页

GLSL公式类型expression或body，可定义辅助函数。参数行有显示名称、公式变量、最小/最大/步长/默认值，最多16项；变量名与公式中标识符对应，系统负责槽位绑定。“当前公式中未使用此参数”是使用提示，不等同于编译失败；编译错误状态会阻止保存。
右侧参数试调仅影响预览，保存采用左侧默认值。预览时间使用秒，可播放；支持time的图形才有内置运动。
公式编辑和创作文件预览中，右侧图像与状态固定显示，下面的参数/播放区独立滚动，长列表不会把预览图带走；较矮窗口会缩小预览，窄屏需先滚到预览区。不要把预览试调误当作已保存默认值。
“验证并预览”检查当前草稿；“复制修复信息”交给AI定位错误，“导出创作文件”保存公式JSON。用户需要编写新公式时推荐创作Skill；效果指导Skill不要求用户手写槽位号或修改内部资源ID。

## 生成器页

可粘贴或选择生成器JSON，定义原生RGBA输出及多个GLSL渲染步骤；不需要模板选择。最多64个参数、16个步骤，每步可读取前面步骤的最多三个纹理。验证通过后显示参数控件，滑动会即时更新预览及保存默认值。编译失败保留上次预览，修复后才能保存。可导出生成器JSON，图库“导出资源”则打包全部依赖；“导入文件”也支持生成器JSON。

现有烟雾、火焰等内置生成器可直接在图库编辑参数并另存；自定义生成器还可重新编辑代码。GLSL 可读取 time（秒）；烟团、雾气、湍流火焰、火花、分叉闪电、浮尘、胶片颗粒，以及动态水纹、焦散、篝火和三种体积效果均支持时间演化。前七项可通过“动画速度”控制运动，设为 0 时静止；相同种子、参数和时间可复现结果。生成器预览时间可手动拖动，节点时钟支持速度、偏移与冻结，参数也可添加关键帧。没有跨帧模拟或用户JavaScript执行。需要制作新算法时推荐创作Skill中的生成器规范，效果指导Skill负责说明入口、参数与操作。
