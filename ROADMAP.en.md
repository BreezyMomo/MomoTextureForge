# Current scope and future directions

<!-- doc-language -->
[简体中文](ROADMAP.md) · [English](ROADMAP.en.md)
<!-- /doc-language -->

The five foundational [expansion areas](plans/texture-tool-expansion/README.en.md) are implemented rather than a pending checklist. Start with the [manual](docs/README.en.md) for usage or [development guide](docs/development.en.md) for maintenance.

| Area | Current boundary |
| --- | --- |
| Web creation | Graphics/generators, composition/arrangement, effects, animation, image processing and resource management; query actual catalogs/schemas |
| AI | Offline native-project authoring and structured MCP reads/writes on user-enabled pages; no automatic access to other tabs |
| Shaders | Separate graphic generation from image processing; Unity covers reviewed analytic graphics and unified handdrawn postprocessing only. See [delivery scope](docs/14-shader-reference.en.md) |
| Material preview | Sphere/plane/cube, lighting/material controls, Sobel/Scharr normals, flips and pre-smoothing; works in static websites |

Potential demand-led work includes more graphic/postprocess engine adapters, Player/mobile verification, AO, normals from four directional photos and custom models. These are not delivered capabilities or scheduled commitments. New Shaders follow [responsibility rules](skills/texture-forge-author/references/shader-architecture.en.md).
