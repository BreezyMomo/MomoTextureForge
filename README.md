# Momo Texture Forge

本仓库是独立开发仓库，后续源码、测试和构建在此维护，无需 Unity 或 Momo 框架。

## 快速开始

需要 Node.js 22 或更高版本。在仓库根目录执行：

```sh
npm ci
npm start
```

打开 http://127.0.0.1:8787/ 。指定端口可执行 `npm start -- --port 8799`。浏览器中的图形库和草稿按访问地址保存；继续使用原地址可沿用原有本地数据。

```sh
npm test
npm run validate:definitions
npm run build:standalone
```

独立 HTML 生成于 `dist/MomoTextureForge.html`。单独重建两个 Skill：`node build-authoring-kit.mjs`。`node_modules/`、`dist/`、`test-results/` 不纳入版本控制。

## 常驻图形列表

图形列表独立于作品并自动存储在当前浏览器/工具地址下。新建、打开项目和刷新均保留；项目附带资源只服务画布，不自动加入列表。需要常用项时手动保存或从图库加入。保存/分享项目仅打包画布依赖，不包含整个列表；旧草稿列表在首次升级时迁移，之后手动移除与空列表均持久保留。自定义资源依赖同时保留，画布撤销不改动列表，列表编辑仍可撤销。列表不跨设备/域名同步。

## 图片确认保存

图库保存/导入以处理结果为准：有处理的位图按原始分辨率固化为PNG，去除处理前图片和恢复参数；导出项目/组合也固化旧位图资源的副本。编辑过程中可对比输入，保存后从最终图片继续编辑。SVG保留矢量；未处理图片可直接复用字节。节点颜色/布局/动画不受影响，已有库和旧文件不批量改写。PNG不保证比原JPEG更小；固化避免重新加载时执行背景处理等工作。

## PSD 矢量轮廓（2026-10-15）

“导出…”新增“PSD · 矢量轮廓（效果简化）”。它直接写入 PSD 形状图层（路径＋单色填充），不是位图智能对象，也不是 SVG。原“PSD · 当前帧分层文件”仍用于尽量保留完整外观。

- 默认透明度阈值 0%：按当前帧每个可分解节点/必要合成部分的实际 GPU alpha **严格大于 0** 判断区域；黑色但不透明的像素也保留。阈值可设 0～99%，严格超过阈值才保留。
- 先提取被保留像素单元的并集边界，保持闭合轮廓、孔洞和内部孤岛，合并共线边；对角接触区域保持独立闭合路径。形状包含真正可编辑的路径锚点，精度取决于导出采样尺寸，不能称为原始解析几何。
- 默认开启“轮廓平滑（抗锯齿）”：简化轮廓并为连续弯曲边缘生成受限贝塞尔切线，明显尖角、微小区域和直线尽量保持。平滑可能在边缘产生约1像素偏差；导出前检查远离边界的实心/透明区域及孔洞/孤岛数量，受影响的部分自动退回原路径，完成提示显示平滑/保留数量。真实路径通过浏览器2D绘制生成抗锯齿图层缓存与合成图。关闭时精确保留像素单元边界，放大可见阶梯。抗锯齿不恢复原羽化过渡。
- 星形排列阶梯修复：平滑开启时，在像素预算与参考边长范围内自动采用1～4倍精细源采样，再换算成文档坐标；逐条闭合轮廓拟合，曲线不安全时尝试简化直线多边形/更小误差，最后才保留局部原路径。密集轮廓相互影响时逐步接受拟合（最多32次全层试验，优先较大区域），避免单个细节导致整个排列回退。抗锯齿保护检查比较真实参考覆盖值，不把原半透明边缘误判为必须全实心。完成提示按路径数显示平滑与保留。采样更精细可能改变极小碎片的范围/数量；关闭平滑仍使用原导出尺寸的精确像素单元规则。
- 羽化/抗锯齿的非零范围会成为实心轮廓，**不是自动恢复羽化前硬边**。默认 0% 会保留最外侧非零范围，提高阈值可收紧轮廓；导出面板标记当前节点羽化被简化。噪声的每个像素若都有非零 alpha，结果可以是完整矩形。
- 每个导出部分使用最不透明采样点的颜色作为单色填充。渐变、多色和像素级半透明过渡不保留，节点整体透明度保留。背景若启用则也是矩形形状图层。隐藏或无超过阈值像素的部分略过；整个画面为空且无背景时拒绝导出。
- 遮罩/反向遮罩已参与原始区域计算，结果形成轮廓和孔洞；不能独立编辑原蒙版。复杂变换、排列或跨节点效果会先按原 PSD 规划合成相应部分，再取单色轮廓，不能保留合成部分的独立子节点。
- 高度、法线和 RGBA 通道不参与该模式，统一使用颜色输出的透明度。单边 4096、总图层采样 32M、单层边界 200K、文档锚点 50K 预算；超限明确拒绝，可降低尺寸或提高阈值。取消在图层之间生效。

已验证真实浏览器/离线 PSD 下载、102 项单测、旋转星形网格回归、独立 PSD 解析和路径强制重绘；浏览器与其他渲染器的边缘抗锯齿可能略有不同。本机没有 Photoshop，PS 原生打开/编辑验证仍待用户试用。

## Photoshop PSD 导出（2026-10-15）

刷新工具，顶部“导出…”选择“PSD · 当前帧分层文件”，按画布比例设置像素尺寸后导出。输出 RGB 8 位 PSD，使用当前作品进度，忽略单独预览、辅助框和查看缩放；不保存动画时间轴，隐藏节点不导出。PS 可用性仍需原生 Photoshop 试用确认，本轮通过浏览器导出与独立 PSD 解析/合成检查。

- 普通节点导出像素图层，名称和可拆分的中性组合保留。关闭透明背景时提供独立背景图层。
- 圆形、圆环和椭圆在纯色（自定义颜色、填色为纯色）、羽化为 0、默认 UV、无排列/蒙版/反相/后处理、图形未越出自身区域时，写成带可编辑路径与填色的形状图层。支持节点位置、宽高、轴心、旋转、镜像及保持比例；圆形内孔与圆环通过减去内部路径表达。形状重新渲染时抗锯齿边缘可能与 GPU 缓存略有不同。
- 组合变换、排列、组透明度、组配色/后处理和节点自身蒙版合成对应子树。跨兄弟节点混合、遮罩与反向遮罩合成此前累计内容；加法会将同组后续内容一并合成，以保留 HDR 衰减结果。合成部分名称含“合成”，导出面板提前列明。此版本不提供独立可编辑的 PS 遮罩。
- 高度、法线及自定义 RGBA 输出使用完整合成图层。导出前比较拆层缓存与完整 GPU 画面；超出 3/255 的预乘像素差异时降级为完整合成，避免拆层改变外观。
- 单边上限 4096，图层/背景/合成图总像素预算 32M；大尺寸多层需降低尺寸或先合并。取消在帧/图层之间生效，PSD 最终编码为同步操作。

PSD 编码使用固定版本 `ag-psd 31.0.3`，浏览器编码器与许可证位于 `web/vendor/`，源码服务无需安装依赖或联网。再生成编码器用 `npm ci` 与 `npm run build:psd-vendor`；离线 HTML 内嵌完整依赖许可证，离线 ZIP 同时携带许可证文本。

## 节点编辑器体验更新

- 画布只设置比例（作品设置），预览自动精度、等比显示；100%以适应窗口为基准，像素尺寸只在导出面板设置并保持比例。自动采样最长边1024，复杂作品可能降采样。
- 统一组件库包含基础图形与组合预设；点击卡片仅查看，点击“添加”才插入。均可收藏、搜索和切换列表/网格；保存或导入的组件可继续组合，插入后内部节点可编辑。
- 顶部“导出…”集中PNG8/16、EXR Half、逐帧ZIP、图集和三档尺寸ZIP，导出完整作品并显示摘要。作品设置与节点检查器分开。
- 参数支持滑动条、单项↺重置、区域宽高比例锁定；◆提示受动画控制，修改基础值不会删除轨道。树节点可拖拽排序/改父级，也可使用上移/下移/移入组合。
- “节点区域”显示当前分配边框、中心与轴心，最多128个实例，不额外描无缝副本；辅助框不导出。当前节点路径和单独预览有明确提示。
- 动画默认收起，展开后区分作品进度与节点局部进度。新图形羽化默认0、保留抗锯齿；旧项目羽化保持原值，需要清晰边缘时可将羽化重置。
- 绘制失败保留上次成功画面并显示重试入口；预算前回收旧状态缓存，避免设置切换时新旧缓存一起占用资源。


## 节点树工作台（2026-10-14）

默认入口已切换为节点树版本。图形或组均是节点，预设是可再次组合的完整子树，插入时复制并重建 ID。直接在左侧树中选择任意层编辑；面包屑用于返回上层。数值参数支持滑动条和数字框双向同步，拖动实时预览，一次拖动只占一条撤销记录，关键帧按钮仍位于参数右侧。节点左侧三角按钮展开/收起子树（含蒙版）；名称用于选中。折叠不改变作品与当前编辑对象，页面内保留嵌套折叠状态，刷新后恢复展开。项目格式为 `momo.texture-tree/v1`，预设为 `momo.texture-subtree/v1`，按本轮决议不读取旧三层项目。

- 空间宽高和时间进度是归一化 0～1；像素尺寸、秒数和帧数只在输出中设置。宽高为 0 时节点不可见。默认中心轴心，可调轴心、旋转和镜像；保持比例模式按正方形内容放入分配区域。
- 组先完成内部合成，再应用组透明度、蒙版和父级混合。组排列默认重复整棵内容子树；也可选择“实例内容 → 随机一个子节点”，从已启用的直接子节点中逐位置抽选。5×5 网格每格拥有宽高 0.2 的区域，所以 10×10 输出下每格为 2×2 像素。
- 每节点独立开启无缝重复。组内越界内容在组区域内循环，不开启后代的无缝开关；边界之外仍裁切。基础公式沿用各自原生周期/重复或边缘融合策略，重复不会再为适配自动缩小图形的 UV 缩放。周期图案仍按原周期规则约束频率和旋转。
- 父级进度→子级区间→局部时间→循环/往返/进度映射→节点动画。可倒放、固定百分比、区间外保持/隐藏。参数轨道只影响本节点，支持绝对值、相加、相乘；◇在当前节点动画进度记录关键帧。
- 实例共享内容；尺寸、方向、种子等由排列规则控制，每份可有动画相位偏移。“展开为独立节点”固定当前布局，复制内容及内部动画，保留外层时间和合成，可一次撤销。布局参数动画不会继续驱动已展开的节点。
- 蒙版为专用子树。颜色可继承、自定义或由组统一映射；标量高度独立保留，最终生成颜色、高度、法线或自选 RGBA 通道。
- 项目和子树支持 JSON 保存/打开、自动草稿、撤销/重做。PNG8/16、EXR、逐帧 ZIP、图集和三档尺寸 ZIP 共用完整树渲染，单独预览和查看缩放不改变导出。普通预览和2×2平铺检查始终等比缩放；100%对应适应窗口的显示大小，适应窗口按统一比例完整放入，固定倍数超出视口时滚动查看。

组件库不再提供内置组合卡片，仅展示用户保存的组合。示例区保留一个“召唤特效”，可打开编辑或保存为自己的组件。目录保留296份公式定义，组件库展示296个基础图形入口。脉冲环提供独立入口。

当前资源上限：256节点、12级递归深度、每节点64条轨道/每轨道128关键帧；单边4096、输出16M像素，另受384MiB中间纹理预算和设备能力限制，并非所有组合均能以最大尺寸输出。缓存保留上限128MiB；相位偏移可能增加子树渲染次数。PNG16/EXR需要浮点 framebuffer。图集单边8192/16M像素、序列合计32M像素。

这是节点编辑器首版：图形库支持分类搜索、真实公式缩略图以及两列网格/单列列表切换，按可见范围懒加载并缓存；收藏已恢复；旧版最近使用、复制图片及全局后处理面板尚未迁入；旧源码保留作回归基线，不宣称新界面已经覆盖旧工作台全部交互。

启动仍用 `start.bat`，或 `node serve.mjs --port 8799`。构建单文件仍用 `npm run build:standalone`；分享作品时同时提供 HTML 与“保存项目”生成的 JSON。离线构建产物忽略，不提交。新项目/草稿独立存储，不覆盖旧版草稿。

## 以下为三层工作台历史说明

旧入口和格式说明仅作历史参考，当前使用规则以上面的节点树章节为准。

排列新增“黄金角螺旋”：1–256 个实例，发散角默认 137.507764°，支持布局半径、中心留空（内半径/外半径）、外圈尺寸倍率（相对中心实例尺寸）、整体旋转与保持方向/朝外/沿圆周切线。实例半径按平方根分布；“分布适配”居中并按数量缩小实例。图层、独立蒙版、关键帧和所有导出共用此排列；无缝保持用户选择，开启时仍会跨边缘重复。

新增“弧菱花砖”（OgeeFlowerTile）单体：参考图公式重绘，单线弧形框、斜向连体花芯与四个轴向点。图案分类搜索“花砖”；“图形示例”第一项为黑底白纹，组合 3 列 × 6 行斜向网格。通用排列器新增“斜向网格”（隔行半格），可用于任何图案或独立蒙版，支持关键帧、居中/铺满与无缝；无缝时有效行数取偶数，原输入保留。单体宽高、线粗、羽化、弯曲、花芯、边框比例与点大小共 8 参数。

内置图案已迁移为统一定义：每个图案在 `web/definitions/patterns/<ID>/` 独立持有 `pattern.json`、`formula.glsl` 和可选 `periodic.glsl`，总目录只维护有序索引、分类与公共函数库。支持表达式、多行函数体；现有 296 项定义由统一目录管理，结构、文件与扩展规则见 [图案定义说明](PATTERN_DEFINITIONS.md)。本轮尚无用户公式上传/编辑界面。

本地程序化特效贴图工作台。296 个可见基础图形入口、12 类目录，支持三层合成、蒙版、UV、关键帧、配色、曲线编辑、通用排列和高精度文件导出。位于 `Tools~`，不参与 Unity Runtime、AssetDatabase 或 Player 构建。

## 离线单文件分享

直接发送 `dist/MomoTextureForge.html`，接收方双击用 Chrome/Edge 打开，无需 Node、服务器或网络；也可发送 `dist/MomoTextureForge-offline.zip`（HTML 与使用说明）。全部 296 个图案、公式、样式、示例和验证视图已内嵌。

重新生成：在本目录运行 `npm ci`，再运行 `npm run build:standalone`。esbuild 仅为构建依赖；源码服务运行仍无需 npm 安装。产物在忽略的 `dist/`，修改源码后须重新生成。

离线“导出配置”下载项目 JSON；分享作品时把 JSON 一起发送，对方通过“打开项目”恢复。移动 HTML 或更换浏览器后草稿/收藏可能不共享，重要项目请另存 JSON。复制图片不可用时自动下载 PNG。PNG16/EXR 仍要求浮点 framebuffer。

## 启动

安装 Node.js 22 或更新版本后，双击本目录的 `start.bat`，在 Chrome 或 Edge 打开终端显示的 `http://127.0.0.1:8787`。不需要 `npm install`、Unity 或云端账号。窗口保持运行，Ctrl+C 关闭服务。端口占用时运行 `start.bat --port 8788` 并打开相应地址。

也可以在本目录运行：

```powershell
node serve.mjs
```

浏览器需支持 WebGL2。PNG16 / EXR 额外要求 `EXT_color_buffer_float`；不支持时页面会禁用高精度输出，保留 PNG8。源码 `web/index.html` 需通过服务打开；可双击分享的是构建后的 `dist/MomoTextureForge.html`。服务器仅监听本机，静态资源之外不提供上传或远程 API。

## 制作贴图

1. 左侧搜索中英文图案名，或从分类和缩略图中选择。
2. 右侧选配色；“背景颜色”可直接编辑渐变的最低色标，背景不限于黑色。勾选“透明背景”可用图案亮度作为 Alpha，棋盘格仅用于预览，不会写进文件。展开自定义渐变，可编辑最多 8 个色标的位置和颜色。
3. 切换图层 1/2/3。第二、三层需启用；每层有图案、9 种混合模式、不透明度和独立 UV。混合顺序可用上下按钮调整。
4. 蒙版选择另一个图案，可反相并独立调整蒙版 UV。选定蒙版后显示它自己的参数，也可以录制蒙版参数关键帧。
5. 调整亮度、对比度、伽马和输入/输出色阶。预览尺寸独立于导出尺寸；“平铺检查”显示重复接缝。需要自动对齐时，开启右侧“无缝平铺”，页面自动显示 2×2 检查，预览和导出同时采用无缝策略。

每种图案都有专属参数表，界面只显示该图案实际使用的参数，并使用各自的范围、步进和默认值。例如圆形为半径/内径/羽化，圆角矩形为半宽/半高/圆角/羽化，FBM 包含噪声缩放/八度/增益/种子/速度，Brick 为列数/行数/灰缝/行错位/柔和。参数实际传入对应运算；圆内孔、矩形高度、FBM 八度和增益均直接改变像素。

Brick 的行错位在整行保持一致。默认使用 8 列、12 行、半砖错位；灰缝和柔和按砖格内的比例设置。纵向无缝重复需偶数行，或将行错位设为 0。

“无缝平铺”的自动方式按每个图层和蒙版分别处理：

- Brick、Checker、Grid、Dots、Stripes、Waves 使用整数周期；Brick 错位行及 Checker 自动采用兼容的偶数数量。
- ValueNoise、FBM、Perlin、Turbulence、Ridged、Billow、VoronoiCells、VoronoiEdges 使用周期格点噪声和整数倍八度；外观会与原非周期版本不同。
- Circle、Ring、Polygon、Star、RoundedRect、Cross、Ellipse、Capsule、Gear、HeartLeafTeardrop、Teardrop、Leaf、BezierRibbon 跨边界重复形状。保留旋转，限制有效缩放，使形状及羽化完整落在周期单元内；移动越过边缘时，另一侧自动补回。
- 其余图案采用边缘融合；也可选择“通用”强制采用此方式，调整融合带宽。它可能产生模糊或重影。

周期图案将缩放换算成密度、旋转吸附到 90°，忽略漩涡和极坐标；重复形状也忽略漩涡和极坐标。原参数仍保留，说明区显示实际数量、旋转或缩放，关闭无缝后恢复原始效果。关键帧先插值，再应用约束；数量或旋转跨越吸附边界时会跳变，UV 滚动仍可连续运动。

“平铺检查”控制查看方式；“无缝平铺”控制实际像素，适用于图层、蒙版、透明度、法线、RGBA 和动画输出，所有文件导出共用该渲染路径。无缝指边界处连续衔接；首尾像素中心不是相同位置，不应要求它们严格相等。

齿轮可选“方齿 / 三角齿 / 梯形齿”。齿宽为一个齿距的占比，齿顶宽度为齿顶相对齿根的角宽比例：0 为尖齿、1 为方齿，梯形预设为 0.4，可连续调成自定义齿顶；尺寸、齿深、齿数、内孔和羽化仍可独立调整。尖齿与梯形齿侧边采用直线，齿顶采用平面。齿形快捷选择修改齿顶宽度，不新增独立状态；该参数及齿宽可以录制关键帧，蒙版也支持相同控制。

心形使用圆弧与线段轮廓的距离场；羽化控制到轮廓的真实距离，避免隐式多项式在尖端和两侧产生不均匀鼓包。原配置大小与羽化值可继续载入，但修正后的轮廓有意不同。

水滴 `Teardrop` 和叶片 `Leaf` 位于“扩展形状”，提供半高、半宽、尖端收紧/饱满指数、弯曲、不对称和羽化。轮廓用 32 段非均匀采样并计算到线段的距离，尖端和圆底增加采样密度；仍是有界折线近似。原 `HeartLeafTeardrop` 的 ID 保留，界面名称明确为“心形”，不会把旧心形预设变为水滴。

Star 可选“直边星 / 圆角星 / 旧版波瓣”。直边星用线段连接内外顶点，圆角星圆化星尖；圆角越大，轮廓越饱满。角数、内径比例、外半径和羽化独立控制。旧配置自动保留余弦波瓣轮廓，新建默认直边星。

BezierRibbon 为四控制点三次贝塞尔光带。拖动参数区小画布的圆点，或选中圆点按方向键；也可直接编辑坐标。坐标范围为 -1.5–1.5，Y 正方向向上。起始/末端线宽、光带羽化、绘制进度和圆头/平头独立控制，全部支持关键帧、撤销和蒙版。实际轮廓以 48 段折线采样；小画布显示完整中心线，主预览显示当前进度、宽度、UV 和合成结果。线宽表示完整宽度，羽化在轮廓外侧扩展。

Splat（溅射形）的尖瓣扰动沿圆周连续采样，修正左侧角度分支处的断口；半径、尖角数、种子、羽化和蒙版仍共用原参数。旧预设可直接读取，种子对应的局部轮廓会调整。验证页的“检查溅射轮廓断口”提供实际 GPU 回归检查。

顶部“图形示例”打开八个实际渲染的示例，可点击“编辑此示例”载入全部参数。示例不会覆盖当前页的未保存编辑。

复杂材质、反应扩散及蓝噪声等采用程序化近似；同名项与参考站不保证相同参数语义或逐像素一致。纯几何图案可用 UV 滚动产生运动。

“操控 UV”启用后，在画布拖动平移、滚轮缩放、Shift 拖动旋转、双击复位。键盘 ↑↓ 切图案，Space 播放，R 随机，T 平铺，E 导出；Ctrl+Z 撤销，Ctrl+Shift+Z 重做。输入框和弹窗内不触发全局快捷键。

## 通用图形排列器

右侧“图形排列器”作用于当前图层：关闭、网格、斜向网格、环形、随机或黄金角螺旋。网格最多 8×8，环形/随机最多 64 个。控制行列或数量、实例尺寸、布局半径、整体旋转、环形朝外、位置/尺寸/旋转随机、种子、网格行错位、排列中心和环覆盖比例。相同种子及参数得到相同排列；随机布局允许重叠，以最大标量值合并。

图层与蒙版各自独立；蒙版参数下展开“独立蒙版排列”可调整其布局。UV 用于每个实例的源图；移动整个布局请使用排列中心，调整分布范围请使用布局半径。源图按正方形截取，超出部分被裁切。矢量图案排列使用其标量形式，配色输出不会保留单图案的 RG 矢量预览。

排列先生成源图再采样，支持图层合成、透明背景、法线/RGBA、预设、动画及所有输出。源图边长为目标最长边，至少 64、最多 2048，并受 GPU 上限约束；扩大实例或导出大于 2048 的图时可能看到源图采样限制。有浮点支持时源图为 RGBA32F，手写双线性采样保留精度；PNG8 回退使用 RGBA8。

开启无缝后，排列按纹理周期重复，包括越过边缘的实例；有效最大实例尺寸包含尺寸随机幅度，并限制旋转后方形范围的外接半径到单元 0.45 内。说明区显示实际尺寸，原输入值保持不变。该方式保留源图的 UV/漩涡/极坐标；对排列源图不再吸附其周期数量或旋转。

## 工作台与项目

右栏固定显示当前图层、图案和显示状态；中央显示“合成预览”。四个分区为图形（专属参数/高级 UV）、排列（布局和无缝）、合成（混合/蒙版/配色/高级后处理与预设）、输出（单张/图集/逐帧/批量及序列帧设置）。各区独立滚动，切换图层后控件始终作用于当前图层。

顶部项目栏提供名称、“保存项目”和“打开项目”。项目 JSON 封装为 `momo-texture-project/v1`，包含 v5 贴图状态、名称、保存时间及导出内容/格式选择；也可打开旧版原始状态 JSON。导入先完整校验再替换编辑，失败保留当前配置。项目外层上限 2 MB，内部状态沿用 200 KB 校验限制。

自动草稿默认开启，在停止修改约 250 ms 后保存，并在关闭页面前刷新记录。启动优先读取分享 hash，否则恢复当前来源的草稿，再兼容旧 keep 存档；设置失败会提示保存项目文件。每个来源只有一份最新草稿，多标签最后保存的版本为准；独立项目请保存为 JSON。

图案库提供全部/收藏/最近、列表/缩略图网格与搜索；☆ 收藏不改变贴图。列表一行一项，图标与名称横排；缩略图网格在桌面按两列展示，上图下名，窗口宽度不超过 720 像素时改成一列。最近最多 24 个，收藏和浏览偏好保存在当前来源。中文为主要名称，英文用于算法识别。

“查看缩放”支持适应窗口和 100%/200%/400%；滚轮查看缩放，“拖动画布”平移视图。查看状态与“操控 UV”互斥；棋盘/黑/白预览背景只影响查看，不改变输出背景、Alpha、UV 或文件尺寸。预览分辨率是渲染采样尺寸，查看缩放只改变显示大小。

排列“居中”重置布局中心；“铺满网格”将中心/半径和实例源图方形适配网格单元，同时重置旋转、错行和随机扰动，保留行列数量。环形/随机提供对应适配动作。源图内图案自身的空白会保留，这些动作不承诺任意轮廓完全无缝覆盖。高级扰动折叠，图层与蒙版共用快捷动作和撤销。

## 动画与预设

静态制作默认收起空时间轴；点击“动画 / 时间轴”、播放或关键帧按钮会展开，载入已有轨道也会展开。时间轴范围为一轮时长。点击参数右侧 `◇`，在当前时刻加/删关键帧；已有轨道的参数在提交新值时自动记录关键帧。先记录起点，再移动时间轴调整数值。支持线性、缓入缓出、保持插值；往复模式把整轮时长分为正放和倒放。当前会话切换图案会暂存各类型参数和参数轨道，切回恢复；UV 轨道保持不变。项目载入、撤销/重做会清理类型缓存，缓存不跨浏览器重启保存。

配置格式为 v5；已有 v1/v2/v3/v4 JSON、分享链接与浏览器存档会自动迁移。v1–v3 默认关闭无缝，v4 保留已有无缝设置；旧配置默认关闭排列。旧 Star 保留波瓣轮廓，新增圆角/轮廓槽位显式重置并剔除此前无效轨道。迁移保留已使用的参数和有效轨道，为新增参数设置合理值，清除原版无作用或意义改变的轨道。旧 Gear 保留方齿类型，新增齿宽设为 0.5、齿顶宽度设为 1，不读取旧隐藏槽位或其无效轨道；轮廓改为直边和平齿顶，不承诺原版逐像素一致。Brick 的行数按 v1 旧网格数量的一半恢复，但灰缝输出已改为正确的砖格；不会重现旧版行内跳动。切换蒙版会恢复新蒙版默认参数并清除旧蒙版参数轨道。

预设在“合成 → 预设管理”，保存在当前来源的浏览器 localStorage，最多 40 个，可命名、分类、改名和删除；以相同名称再次保存会更新该预设。预设 JSON 导入先校验全部数据，再按名字合并；错误输入不替换当前预设。工具默认自动保存当前项目草稿，刷新可恢复；旧“保留参数”存档仍可迁移读取。不同端口或浏览器的存储独立，跨机器使用项目或预设 JSON。

“分享配置”只将配置编码到 `#fx=`，不上传。接收方运行自己的工具，将链接主机/端口替换为自己的地址，保留 hash 部分即可。

## 文件输出

| 输出 | 数据与用途 |
|---|---|
| 图案配色 | 渐变 RGB；可将标量高度作为 Alpha |
| 高度灰度 | 三层合成后的标量，用于遮罩、置换等 |
| 法线 Sobel | 高度求导得到的切线法线，编码到 0–1 |
| RGBA 通道 | 独立选择高度、反相高度、法线分量、斜率或常量 |
| 翻转书 | 指定行列数、帧尺寸，按时间采样生成图集 |

“透明背景”适用于图案配色、高度灰度和翻转书，并保留到 PNG8/16、EXR、图集和逐帧输出。Alpha 来自后处理后的标量高度并钳制到 0–1，与 RGB 颜色无关；例如白色背景也可透明。提高亮度或输出低色阶会使原空白区域产生 Alpha。法线仍输出不透明数据，RGBA 的透明度由 A 通道单独选择。

单个矢量图案在配色模式输出 RG 向量，0.5 表示零分量；多层时参与标量合成。高度模式可查看其标量形式。

PNG 支持真正的 8/16bit RGBA；16bit 从 RGBA32F 渲染读回，不经过 8bit 预览。PNG 数值钳制到 0–1。EXR 使用 half 通道、无压缩或 ZIP16 无损压缩，保留负值和 HDR；PNG/EXR 编码器没有运行时第三方依赖。预览本身为 8bit。

“输出”页选择单张、图集、逐帧或批量，摘要显示尺寸、格式/位深、透明度和帧数。图集与逐帧可使用当前配色/高度/法线/RGBA 模式；旧 mode=4 图集配置继续按配色读取。批量 ZIP 输出 256/512/1024 三档 PNG，按输出宽高比例生成，不使用自定义像素尺寸；项目配置单独通过“保存项目”备份。旧 mode=4 的批量兼容路径使用 64/128/256 帧尺寸。逐帧 ZIP 包含所有帧与 `manifest.json`；0 号帧位于图集左上角，从左到右再从上到下，采样不重复末尾终点。复制图片始终为 PNG8。

单张最多 16,777,216 像素、自定义边长最多 8192，并受 GPU 最大尺寸约束。图集边长最多 4096，最多 8×8 帧。大图、多层噪声和法线更耗时；导出期间锁定编辑，有进度和取消。浏览器可能询问是否允许连续下载，按需要允许当前本机来源。

支持浮点 framebuffer 时，法线/RGBA/HeightNormal 先渲染带一像素邻域的高度图，再计算法线；中间图各边增加 2 像素，因此需要相应显存和 GPU 纹理边长余量。不支持浮点时仍使用直接计算路径，该回退尚未在真实显卡上验证本轮改动。

Unity 导入数据贴图时关闭 sRGB；法线按项目的法线约定与 Texture Type 设置，图集在 Shader/VFX 中配置相同行列数。可根据项目需要调整过滤、Wrap Mode 和纹理压缩。本工具不自动写入 Assets 或配置 Unity Importer；Unity 导入链路需在消费项目验证。

## 检查与开发

```powershell
npm test
```

测试验证目录、状态边界、关键帧、PNG16、half EXR/ZIP、CRC 和扫描行。访问 `/validate.html` 可用实际 WebGL2 检查全部图案、合成、法线、RGBA、UV、关键帧和 HDR；可下载验证 JSON 和高精度样本。使用说明也提供全图案诊断。

`tests/dom-check.mjs` 为可选 Happy DOM 编辑器测试，参数为其 `lib/index.js` 的路径；GPU 被模拟，不作为渲染证据。`tests/native-gpu-check.py` 为可选 ModernGL 数学交叉验证，把 GLSL ES 的头改为桌面 GLSL 330，不代表浏览器测试。辅助依赖自行安装到工作区忽略的测试目录，工具运行无需它们。

源结构：`catalog.js` 目录与默认参数，`parameter-layouts.js` 全目录专属 schema，`patterns.js` 独立数学表达式，`state.js` 校验/迁移/动画，`renderer.js` WebGL2，`encoders.js` 文件编码，`app.js` 编辑器。底层最多四个 vec4 只是传输槽，参数控件与校验始终使用所选图案的 schema。着色器按已选图案和模式生成，裁剪不可达函数并缓存最近 24 个程序。

Momo Texture Forge 是本地运行的图形与纹理创作工具，支持公式、图片和 SVG 资源、节点组合、动画及多格式导出。


## 新增排列方式

在“排列 → 排列方式”选择，顶部“图形示例”可打开七个现成样例：

| 方式 | 专属参数与行为 |
|---|---|
| 沿路径 | 四控制点贝塞尔（拖动或方向键）、近似等弧长按数量/间距采样、起止进度、末端尺寸、切线/法线朝向；反向进度反向排列 |
| 均匀随机 | 最小中心距离、目标数量、种子；有限候选生成，区域不足时减少实际数量，不强行缩小间距 |
| 多圈环形 | 每圈数量、圈数、内半径、圈间错位、外圈尺寸、朝向；总数超256时减少有效每圈数量，保留完整圈组 |
| 规则螺旋 | 圈数、内半径、等弧长实例数量、尺寸变化、朝向 |
| 镜像 / 放射对称 | 对称份数、镜像成对、偏角、半径；成对翻转源图，超256时减少有效份数；随机扰动会打破严格对称 |
| 六角密排 | 横/纵错列、行列数、布局半径、实例尺寸；行距为横向间距的sqrt(3)/2，最多8×8 |
| 按密度散布 | 从现有296图案选择独立密度图，展开其专属参数，设置阈值/对比度/最小距离/目标数量；亮处更密，黑处不生成 |

新增模式最多256个实例（六角网格64），图层与独立蒙版均可用，参数支持关键帧和项目保存。密度图案类型选择不做关键帧，其参数可以；密度源以128×128标量采样，细线可能因采样或候选不足而缺少实例。数量摘要显示实际生成数，路径间距和散布的实际数量可能低于上限。中心距离不等于轮廓防重叠。

位置由CPU确定性生成后上传小型浮点实例表，复用原有标量源图、合成与导出。无缝保持显式选择；开启会跨边缘重复，随机散布按周期中心距离检查。修改密度/种子/最小距离可能使候选集合跳变，不能保证粒子身份连续。旧16/20槽配置不变，新模式采用58槽扩展；图案公式参数ABI仍16槽。图片导入见下文；暂不支持文字上传。

## 六类排列入口

排列方式收拢为六类（另有关闭）：网格排列、随机散布、环形排列、螺旋排列、沿路径、对称排列。

- 网格排列：矩形、斜向、六角作为子类型。
- 随机散布：最小中心距离为0时允许聚集，大于0时限制间距；密度分布可选择整个区域或使用密度图案，两者共用距离、数量和种子。空间不足时显示实际生成数量。
- 环形排列：圈数1为单圈，大于1显示圈间错位与内半径；每圈数量、覆盖比例、朝向共用，总数上限256。
- 螺旋排列：黄金角和规则螺旋作为子类型，分别显示专属参数。
- 沿路径与对称排列保持独立入口。图层与蒙版使用同一套分类界面。

本轮不提供旧项目兼容迁移；内部采样算法编号继续复用。前文的各算法名称对应这些分类中的参数组合，不再各占一级入口。

## 节点动画轨道编辑器

展开预览底部“动画与时间轴”，左侧是当前节点的参数轨道，右侧是 0～1 时间尺、菱形关键帧和红色播放头。参数旁的 ◇ 用于添加轨道/关键帧，添加后面板自动展开；已有轨道的 ＋ 在当前节点动画进度添加关键帧。

点击时间尺或关键帧进入节点局部预览，默认保留完整作品（可用“单独预览”开关隔离当前节点）；此操作不改变项目时间规则、保存内容或导出。点击“返回作品时间”恢复整体播放；拖动作品进度也会退出局部预览。

选择菱形后可拖动时间，或在下方精确编辑时间/数值、设置轨道插值与绝对/加法/乘法作用。拖动结束只产生一次撤销记录，同一轨道移动到已有时间会合并并保留移动关键帧的值；删除最后一帧会移除轨道。支持删除按钮及非输入控件焦点下的 Delete/Backspace。当前为单帧编辑，尚无多选框选与曲线切线编辑。


### 组合总览与局部编辑

时间轴默认显示所选节点及全部后代（含蒙版）的树形轨道，节点可折叠；点击轨道选择参数所属节点，不改变总览范围。顶部路径返回上级，“整个作品”查看全部轨道。

总览使用当前组合的动画进度 0～1。直接子级的蓝色播放区间条可整体拖动或拖动两端；双击区间或点击节点“编辑”进入该节点局部关键帧。更深层节点使用“父级区间”进入直接父级后调整区间，避免跨循环/非线性映射反解。节点行汇总本节点关键帧，参数行显示映射后的标记，点击标记定位组合进度；总览标记不可拖动，局部模式保留关键帧编辑能力。

映射标记基于 1024 分段采样与交点细化，跳变不会被当作经过所有中间关键帧。极短时段和高速多层循环可能漏标，冻结/保持区段只显示进入时的标记；不作为逐帧精确导出结果。排列实例相位偏移不展开为独立轨道。项目与导出仍使用原动画数据，预览覆盖不保存。

### 序列导出 FPS

导出界面设置“每秒帧数（FPS）”（1～120，新项目默认30）和播放秒数，总帧数自动计算。循环为 ceil(FPS × 秒数)，不包含时间终点；非循环额外追加终点。按 1/FPS 秒采样，非整数时长的末帧截到终点。例：24 FPS × 3 秒，循环72帧、非循环73帧。图集、逐帧ZIP和批量图集共用此规则，图片不携带播放速度，使用端需设置对应FPS。

旧节点树项目缺少FPS时，由旧帧数和秒数推导并约束到1～120；原来的总帧数字段成为派生值。总帧数不再截到256，超过10000会明确拒绝；原有像素/图集尺寸预算继续适用。

### 组件试编辑

点击组件卡片进入独立试编辑会话，左侧切换到组件节点树，右侧可编辑图形、排列、合成、动画，支持内部子节点和UV操作。顶部“添加到作品”将整个试编辑结果复制到作品顶层末尾，并选中新节点；整个插入可一次撤销。单个顶层节点直接保存；多个顶层节点仅在保存/插入时使用必要的中性组合承载。

“返回作品”恢复原作品选择、时间、参数页、缩放、背景和画布滚动位置。试编辑有独立撤销/重做，同一页面内切换组件保留各自调整；“恢复原始组件”可撤销；“保存为新组件”持久保存整个试编辑结果，左侧“保存选中为组件”可保存子节点。原组件不覆盖。试编辑缓存仅本次页面会话有效，刷新前请添加到作品或保存为新组件；试编辑不会写入作品自动草稿。预览期间保存项目/分享项目按钮禁用，避免把试编辑误当作品保存。

### 更新个人组件

个人组件试编辑提供“更新原组件”：确认弹窗显示组件名称，并说明已有作品实例不会改变。确认后覆盖整个试编辑结果，保留组件ID、名称、收藏与列表顺序，刷新缩略图；取消不写入。提供本次会话最近一次“撤销更新”，只恢复组件库版本，当前试编辑内容继续保留。更新后“恢复原始组件”以最新保存结果为基准。内置组件只能另存。试编辑隐藏“单独预览”，保持完整组件显示，返回作品恢复原预览状态。


### 试编辑层级与并列节点

节点树顶部独立显示“← 返回作品 / 组件名称”，下面直接显示内容节点，不暴露试编辑容器。点击节点树空白取消选择，右栏不显示容器参数。“＋组合”创建顶层空组合，拖到树底“拖到此处移至顶层”区域可将已有子节点移到顶层；取消选择后从组件库添加也进入顶层。

单根组件保存根节点本身，不增加层级。多根组件使用组件库元数据 forest=true 标记中性承载组合，重开时展开为并列节点，更新不会累积外层；导入导出保留该标记。插入作品时多根以组合整体插入。旧组件没有此标记，不自动拆层，避免丢失历史外层的动画、排列和合成效果。

层级排序与父级调整统一使用拖动：节点上下边缘调整顺序，组合中央移入，树底投放区移回顶层。上移、下移及移入组合下拉已移除，添加蒙版组保留。

作品节点树同样隐藏内部画布根，直接显示内容节点；点击空白或顶层投放区取消选择，右栏不显示根参数。画布比例等仍从作品设置进入。画布根统一归一化为中性容器，旧根的排列、时间、透明度、颜色、蒙版及后处理不再参与渲染。实际内容子节点与组件根参数保持原样。


### 顶层添加与整体打组

所有组件添加（包括试编辑后的添加）默认追加当前画布顶层末尾，不受选中节点影响；需要嵌套时再拖入组合。预览区右上角、“单独预览”旁的“保存到组件库”保存当前节点及其全部子节点。节点树顶部“添加顶层节点”将所有当前一级节点按原顺序包进一个新的中性组合并选中；空画布时创建空组合，整个动作可一次撤销。“＋组合”继续用于添加并列空组合。

### 绘制抗锯齿与亚像素边界（2026-10-15）

实时绘制的排列/变换在缩小中间纹理时积分四个覆盖采样，预览、PNG和PSD共享；原有基础图形fwidth抗锯齿保留。此改进增加缩小阶段采样开销，没有改变项目文件格式。

四角度星形的绘制覆盖误差平方和从36.64降至9.33（对照4倍采样参考，非原生PS指标）。107项单测、浏览器/离线导出和独立PSD重绘通过。低分辨率、密集细节仍可能保留细碎轮廓；尚未支持任意节点直接输出解析几何，也未验证用户截图对应原项目。
# 节点多选与画布编辑


- 节点树：Ctrl/Cmd 单击增减选择，Shift 按当前可见顺序连续选择；主选节点显示金色边框，其他所选显示蓝色。右侧参数编辑主选节点。
- 所选节点可以一起拖动排序/移入组合、复制、删除、显示和隐藏。父子同时选中时只操作最高层，避免重复变换。组合所选（Ctrl/Cmd+G）要求同一父级；Ctrl/Cmd+D 复制，Delete 删除。组合保留所选相对顺序，放在第一个所选节点的位置；原来夹在中间的未选节点会排在新组之后，混合结果可能随顺序改变。
- 选择/变换：单击可见图形选中，拖动移动；单选时八个控制点调整区域，外侧圆形手柄旋转。多选可整批平移，缩放/旋转针对单个节点。Shift 移动锁轴、缩放锁比例、旋转按15度吸附；Alt 拖动临时关闭吸附。
- 空白处拖动框选完整落入框内的节点，Ctrl/Shift 框选追加。双击组合进入其子节点范围，通过“返回上层”或 Esc 返回。Alt 单击轮换重叠候选，右键列出候选节点。选择优先保留已选节点以便拖动，重叠时可用 Alt 切换。
- 编辑轴心：拖动轴心会补偿位置，保持图案原位。内部 UV 独立编辑；选择/变换、编辑轴心、移动画布、操控 UV 相互切换。鼠标在预览内按住 Space 临时平移，松开恢复原工具；滚轮缩放视图。
- 画布金框是输出边界，蓝框是节点分配区域。辅助线与控制点仅在编辑界面显示，不进入导出。重复副本共享源节点，只有当前副本显示手柄；需要独立编辑时先展开实例。
- 一次拖动只产生一个撤销记录，Esc/失焦/指针取消会恢复拖动前状态。普通模式不能拖动已有动画控制的参数；开启录制写入当前节点进度的关键帧，基础值模式修改基础状态。组件试编辑和作品各自保留选择与撤销历史。


图案库去重：已实际删除11个重复或无效定义及其公式文件，不保留旧ID重定向或索引迁移。当前284个注册定义、284个可见入口。蜂巢网格和窄环渐变作为保留图形的参数预设，位于对应卡片“更多”菜单；支持有意义的中文同义词搜索。


## 内置公式

当前注册 284 个图形，实际目录以 `web/definitions/builtin.json` 为准。参数由各图形的定义文件声明，支持灰度、蒙版、法线及部分图形的矢量输出；无缝行为按定义选择周期、重复或边缘融合。



### 移植后整理与通用轮廓

当前284个图形全部可见；五组重复入口合并：DialMarks→CompassTick（刻度环）、DotHexStagger→Dots（隔行错位）、ScreenTone→Halftone（径向/线性/噪声灰度来源）、PulseRings→RingPulse（平滑/指数衰减）、Sweep→ConeGradient（角向渐变）。Gear支持直边/圆齿；GearTeeth改为真正的直线齿条；新增LineSegment，可设端点、线宽、圆头/平头。旧ID及参数数组不做兼容迁移。按用户选择，IrisBlades恢复移植前的光阑叶片公式和参数，未改为多边形光孔。

修复分叉闪电接点与种子、真正圆角多边形、格栅边框、星锁阵线宽耦合、角度裁切和放射光芒接缝。圆弧环/扇形使用角度制起始角、扫过角与独立端点羽化；360°无角度裁缝，0°为空。Bell合并重复尺寸控件；Swipe的边缘形状与宽度独立。纤维方向更名为纤维拉伸；蓝噪声点、多方向波纹、反应扩散风格纹理等名称按真实公式能力调整。

节点“合成→轮廓处理”提供关闭、外描边、膨胀、收缩。作用于排列、蒙版、配色和后处理之后的节点结果，组合先合成再处理；外描边只输出膨胀后的外侧差值。宽度按本地节点区域短边比例（0～0.1），支持关键帧、组件打包及项目保存。处理基于透明度的最大/最小值，颜色和高度随选中的样本一起传递；无缝节点跨边界重复采样，普通节点区域外视为透明。GPU使用八边形近圆核（不是精确欧氏圆），由四方向连续区间滤波组成，抽样次数随半径对数增长。PSD将带有效轮廓的形状/组合按最小受影响子树栅格化，避免错误导出原始矢量轮廓。



## 图形内置时间

使用时间变量的图形提供“自动播放”，默认按累计秒数 × 运动速度 + 时间偏移驱动原公式。关键帧仍使用节点局部0～1进度；时间轴循环不重置公式时间，切换组件保持累计时间。速度是时间乘数（可倒放），不是积分速度；动画化速度会直接重映射时间。关闭自动播放捕获当前公式时间（已有手动时间轨道时保留），可在-36000～36000秒定格或录制关键帧。

节点保存 `shapeClock: {follow:true,speed:1,offset:0,value:0}`。自动时间独立于父子时间映射和实例相位；需要这些控制时使用手动时间轨道。播放/暂停控制两个时钟；重新播放将当前范围进度与累计时间归零并开始播放。拖动定位将累计时间设为当前范围进度×播放时长。单帧及PSD导出捕获当前累计时间；序列从零按帧对应秒数计算，重复导出一致，不承诺无缝循环。UV滚动仍使用原节点进度。

图形时间依赖从实际公式读取，参考矢量包装函数会检查函数体，避免把仅有time形参的静态流向图误标为动态。渲染缓存按实际时间依赖失效，不再依赖是否存在T槽参数。`shape-time-validate.html`可运行手动时间、缓存、关键帧、UV独立性、无缝路径与保存回读的真实WebGL回归。

播放、播放时长和进度条常驻预览下方，位于“动画编辑与时间轴”折叠区外。展开仅用于轨道/关键帧编辑；收起不暂停，Space播放/暂停不自动展开编辑区。

播放状态在切换组件库图形、返回作品和添加到作品时保持；播放中切换继续播放，暂停后切换保持暂停。各试编辑会话仍保留各自进度与参数。

### 动态图形筛选与默认运动
组件库“组件类型”可选择“动态图形”，与搜索共同生效；目前67项，按公式实际时间依赖筛选。溶解噪声、侵蚀遮罩通过阈值关键帧控制，不显示内置时间控制。折线、漩涡噪声、扫描线、LED点阵默认具有轻微运动；传送箭头和漩涡之门默认速度已放缓。默认值仅影响新建/重置参数，不覆盖作品中保存的参数。

## 组合杂排（2026-10-17）

排列“实例比例”默认“保持设计比例”，让每份图案按物理格子短边适配，位置仍遍布整个区域；宽/竖画布不再压扁圆环和花朵，旋转也按实际宽高计算。需要拉伸时选择“随区域拉伸”。未排列节点保持原有区域适配；新旧缺省配置的排列均默认保持设计比例，历史矩形格子的拉伸效果可显式选择恢复。防堆叠间距和周期检测同步使用短边尺度/实际区域宽高，改变画布比例可能重新分布；保存、选区、展开和导出使用相同逻辑。

单张PNG导出使用逐步合成和及时释放：保持选定像素尺寸/PNG位深，不受预览的384MiB临时纹理预算或单帧求值次数门限阻止。重复源最多缓存2份，用完清理；高度缓冲单通道保存32位浮点，不降低数据精度。支持硬件浮点混合时只绘制图案覆盖区域，其他混合仍按原公式合成。复杂作品可能更慢；实际显卡/浏览器分配失败或上下文丢失仍会明确报错，并不能保证任意作品在所有设备上都能导出。其他格式仍沿用各自流程。

“实例内容”也可选择“按顺序循环（取模）”：按排列点生成顺序，从节点树已启用的直接子节点中循环选择。例如3项对应1、2、3、1、2、3……，同一点序号的选择不受种子和时间影响；种子仍可能移动随机散布点。改变候选顺序/数量会改变映射。保存、导出、选区和展开保留这一规则。

随机散布的“防堆叠”适用于整个区域和密度图案，可与随机/取模子节点混排同时使用。按本次实际选中内容的可见外包圆、实际尺寸和旋转避让，透明留白不再预留整块区域，尺寸随机也不再按最大值统一预留。128×128固定透明度采样含边缘余量；细长/空心图形仍保守，极细或极淡细节受采样精度限制。子节点效果参与采样，整个组合在排列后应用的效果不作为单体碰撞几何。“额外间距”和“最小中心距离”继续生效，无缝检查跨边缘邻居。放不下时显示实际/目标数量并减少实例；可减小尺寸/间距或扩大布局半径。默认关闭，设置随项目和组合资源保存。

将多个图形放进同一组合，开启网格、环形或随机散布等排列，在“变换/排列 → 实例内容”选择“随机一个子节点”。每个位置等概率选一个已启用的直接子节点，允许重复；子组合视为一个候选，遮罩不参与抽选。调整“杂排种子”更换结果，与高级排列种子共用。默认“整个组合”保留原行为；关闭排列时仍显示全部内容。刷新、动画和导出保持相同选择，展开为独立节点也保留结果。模式随项目/组合资源保存；请用新版工具打开。

## 多地址远程图库

图形库 → 远程图库可添加多个HTTP(S)目录订阅，独立启用、刷新和设置自动下载新版。下载资源可离线使用；自动更新缓存不替换常用图形列表、个人修改或画布。静态版同样支持，远程服务器需允许跨域。发布步骤、格式和限制见 [远程图库说明](REMOTE_LIBRARIES.md)。

“帮助 → 下载效果指导Skill”包含独立的[远程图库使用与管理](skills/texture-forge-effects/references/remote-libraries.md)手册，按订阅使用、纯静态本地管理器和手动Git/Pages/CDN发布分别指导，含版本/删除范围与排错；页面下载ZIP与单HTML内嵌下载由同一维护源构建。

### 随包本地图库管理器

运行 `node build-library-manager.mjs --out <图库目录>`，生成自包含的根目录“library-manager.html”和 `manager/index.html`；`build-remote-library.mjs` 也会随输出安装。仅开发构建端需 Node/npm，最终使用者不需要安装运行环境。用新版桌面 Chrome/Edge 打开HTML，选择并授权本地图库目录即可管理，也可以从HTTPS管理页选择本地文件夹。支持ZIP预览导入、目录信息、搜索、下架与恢复，只写入所选目录，不操作Git、不上传CDN。快照保存在当前浏览器，支持JSON备份下载与恢复；会记住已选目录，权限有效时自动恢复，否则点击“继续使用”授权；“关闭图库”会忘记目录。详见 [远程图库说明](REMOTE_LIBRARIES.md)。


“彻底删除”会移除所选目录条目并删除当前引用的 ZIP 和缩略图，共用文件保留；历史版本和此前移出目录的文件不自动清理。删除前需确认，旧项目下载可能受影响，目录快照/JSON 不能恢复已删除文件。先保存目录再清理文件；清理失败会列出未删除路径，需检查权限后手动清理。本地删除要自行发布后才影响远程，浏览器已有缓存不受本地删除直接影响。
